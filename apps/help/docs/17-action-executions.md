## 基础动作

在“数据 → 对象类型 → 动作”中查看可以执行的动作。自定义类型默认生成新增、编辑和删除基础动作；系统业务继续使用内置业务动作。基础动作可停用，旧通用保存入口也受停用约束。

新增和编辑采用属性表单。“不设置／保持原值”不提交该字段，“设为空值”提交明确的空值。只有允许的字段可写；必填属性不能清空，关联需要通过建立或解除关系操作。

## 最近执行

在动作页展开“最近动作执行”，可按成功或失败查看最近 20 次记录。记录包括动作名称、App/MCP/核心入口、时间、尝试次数和失败说明；悬停动作名称可查看完整执行标识。

完整记录也可在“数据 → 动作执行记录”中查询、筛选和统计。执行记录只读，不能直接新增、修改或删除。这里只记录经过通用动作执行入口的请求，不代表每一条底层 SQL 或所有历史业务操作。

## AI 与重试

MCP 的 `invoke_action` 返回 executionId，`list_action_executions` 查询执行结果。纯数据库动作支持可选的 `options.idempotencyKey`：同一键和同一参数重试，返回第一次成功结果，不重复创建记录；相同键用于其他动作或其他参数会被拒绝。修正输入后应使用新的键。

幂等成功重放不会再次写业务数据；失败重试继续检查当前规则。执行记录不返回幂等键、参数摘要、私有结果缓存或任务认领令牌。

`preview_action` 只读取动作定义和可识别对象的修订。执行时带回 expectedDefinitionRevision 和 expectedObjects，过期即拒绝，需要重新查看。预览不能穷尽新建对象和业务联动影响，也不能代替课程样课确认或创作审核。

## 受限组合

自定义动作可顺序执行对象/关系操作，并调用明确允许的短数据库业务命令。当前可组合：新增待办、更新待办、完成待办、撤销完成、更新计划条目；动作目录中的 composable 说明是否允许组合。

组合可以引用前面步骤的结果，例如创建阅读记录后，用它的主键调用新增待办，再建立关联。所有数据库步骤在同一事务中完成；后一步失败时，前面的业务写入回滚，并留下失败执行记录。

文件导入导出、工具文件安装、联网、模型调用和人工审核不能进入这种数据库组合，也不支持通用幂等选项；继续使用对应业务的恢复、任务和确认流程。执行记录写入失败不会把已提交的文件业务伪装成回滚，此时返回审计不可用提示。
