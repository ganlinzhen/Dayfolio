---
title: 设置
description: 配置后台 Agent 的本机 CLI、模型与连接检查
---

侧边栏底部点击「设置」，第一个设置项是「配置 Agent」。后台 Agent 集中在一个分组卡片内，名称与说明在左，选择控件在右；展开后每行左侧说明、右侧填写或操作。

1. 点击 Codex、Claude Code 或 Gemini CLI 条目，选择并展开该 Agent 的配置；再次点击可收起，收起不丢失当前编辑。路径、模型、安装登录命令与连接检查都显示在对应条目内。三者都需要用户在本机安装和登录，App 不内置 CLI；「暂不启用」可停用后台调用，仍可在 Agent 对话中更新新闻。
2. 可执行路径留空时自动查找 PATH、Homebrew、用户本地与 nvm 安装位置；也可点「选择文件」指定绝对路径。路径只填写可执行文件，不附命令参数。
3. 模型可留空，使用该 CLI 默认模型；指定模型需当前账户可用。
4. 未安装或登录时可复制对应命令，在终端执行。Codex 需要 0.163.0 或更新版本；Claude Code 和 Gemini CLI 需要支持无界面执行参数的新版。
5. 可以在条目内点击「复制给ai」，把包含所选 Agent、当前路径与模型的接入提示词粘贴到 Agent 对话中，让它检查本机 CLI、登录状态，通过 Dayfolio 配置工具保存并回读验证。缺少安装或登录时按提示完成；复制本身不保存配置、不启动 Agent，也不采集新闻。
6. 手动配置时，在条目内点击「检查连接」，再点底部「保存配置」。检查不发起推理，不代表网络、模型或搜索额度已验证；Gemini 登录会在实际任务中验证。失败时按提示修正路径、版本或登录。

切换 Agent 时保留各自已保存的路径与模型。配置重启后保留，多窗口修改需重新加载最新版本。离开页面有未保存修改时会提示确认；退出 App 前请先保存。

新闻页的「配置 Agent」跳到本页；「更新今日新闻」使用保存的选择。保存只影响下一次启动的任务，正在运行的任务使用原配置。凭证仍由各 CLI 管理，Dayfolio 不保存密钥；实际采集使用相应账户的额度。对话中采集无需修改此配置。
