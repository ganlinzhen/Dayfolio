## 页面操作区

顶部操作栏集中放置状态切换、优先级和分类下拉、当前结果数量、搜索和「记录」按钮；新增待办输入区位于下方。数量随筛选与搜索变化，待办以细线分隔的列表行展示；自动关联标记只在界面中隐藏，原始标签保持不变。

## 添加一条待办

顶部一行式输入框，从左到右：

- **标题**：输入后按回车立即保存；
- **优先级**：高 / 中 / 低，默认中；
- **安排日期**：默认今天，可选择其他日期；
- **时间安排**：默认「时间段」，填写开始时间（精确到分钟），结束未知可以留空；跨午夜时选择结束日期，明确的结束须晚于开始；特殊情况切换为「仅日期」，无需填写时段。
- **标签**：逗号分隔可填多个，如 `工作,周报`。

填写标题和时间段后回车保存；尚未安排具体时间时可切换为「仅日期」，日期也可暂时留空。

## 筛选与查找

- 状态分段：未完成 / 已完成 / 全部；
- 优先级分段：全部 / 高 / 中 / 低；
- 分类下拉：全部分类、基础待办、学习计划及实际创建的工具分类等；分类归属与日历一致，筛选发生在结果数量限制之前；
- 右侧搜索框按关键词实时过滤（延迟 200ms 防抖）。

## 列表分组

待办以**卡片**形式展示，每条一张：卡片第一行是标题，第二行是元信息（优先级、截止日期、标签、来源），不再挤在同一行，长标题和多个标签都能完整看到。

列表按安排日期自动分组：**已逾期 → 今天 → 未来 3 天 → 稍后 → 无日期 → 已完成**。有明确结束的待办在结束后逾期；仅开始或仅日期的待办在相应日期结束后逾期。跨日安排按结束日期判断。固定时刻使用统一显示时区，浮动安排保持原日期和钟点。逾期分组标红；逾期条目的日期同样标红，今天到期的加粗强调，高优先级在卡片上有红色「高」标记。

## 完成与撤销

点待办左侧的**圆钮**完成；完成后再点一次重新打开。已完成条目标题置灰加删除线，归入「已完成」分组。

## 行内编辑

直接**点待办标题**进入编辑：修改标题、安排日期、起止时间，或切换为「仅日期」，`Enter` 保存，`Esc` 取消。

## 删除与撤销

行尾 `×` 删除，删除后左下角 Toast 提供**撤销**，点击即按原内容重建独立待办；外部订阅不会自动恢复。

## 查看打卡记录

点击待办页头部「记录」进入打卡记录页，查看精确到秒的记录时间、连续天数与活跃情况。点击「返回待办」回到列表，筛选条件会保留。侧栏不再单独展示「打卡」。

## 来源标记

卡片底部的小标签标明来源：**AI**（通过 MCP 由 AI 创建）、**计划**（由学习计划自动生成）；App 内手动创建的不标记。


## 完成记录与活跃情况

### 什么会记为打卡

两类动作会自动写入打卡记录，无需手动整理：

- **完成待办**：在任意面板勾选待办；
- **计划条目打卡**：完成学习计划里的某条安排。

> 手动「每日打卡」入口已于 2026-10-14（v0.15.0）移除（今日页、打卡面板与菜单栏托盘不再提供）；历史「每日」记录保留展示，连续天数与热力不受影响。

### 打卡面板看什么

- 活跃区显示**连续打卡天数**（streak），下方一行 28 个热力点展示近四周活跃情况，悬停可看具体日期；
- 热力点下方给出**近 7 天 / 近 30 天活跃天数**，累计打卡次数在顶部显示。

### 最近记录

下方按时间以细线分隔的列表行列出最近 60 条打卡：主行是来源徽标（区分**每日（历史）/ 待办 / 计划**）与内容描述，元信息行显示实际记录时间（精确到秒）与备注；补记日期与实际记录日期不同时，另外标注「补记 YYYY-MM-DD」。重复打卡保留首次记录时间，仅刷新备注。

### 小技巧

- 断签只影响连续天数，历史记录都在；
- 想让打卡链不断，完成任意一条到期待办或学习条目即可。

## 外部事件关联的待办

HTML 工具的「加入待办」保存本次内容快照，与下述事件订阅分别处理。工具页面的批量预览可勾选事项、跳过已有记录，并显示待办分类；首次确认添加新事项时才创建或复用分类，取消预览不创建。添加后可在「待办」按分类筛选并正常编辑、完成或删除，日历中可单独控制分类显示。重复添加不覆盖个人修改、分类或完成状态，也不恢复已移除记录；不会自动同步来源改期或新增比赛。

关联事件默认跟随来源标题与排期。有效修改标题或排期后转为手动安排；改备注、标签或优先级不会停止跟随。来源取消时，仍跟随的未完成待办清空排期并保留；手动安排保留个人时间，并显示「来源已取消」。时间待定显示相应提示。已完成记录不会因来源更新重新打开。

当前接口支持查询订阅、取消订阅和按双修订恢复跟随；也可以从今日页日历点击订阅待办进入来源详情。日历已提供分类显示面板，工具箱通过「导入 HTML」添加页面，不再安装运行时工具包。

日历中点击「新建日程」旁的更多按钮 →「管理分类」，可以编辑共用分类的名称和颜色，或确认删除自定义分类。删除分类保留待办与完成记录，将其归入基础待办；学习与订阅仍按真实关联归类。隐藏分类只影响日历，待办列表仍可查询。
