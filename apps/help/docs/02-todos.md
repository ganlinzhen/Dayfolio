---
title: 待办
description: 添加、筛选、完成、编辑待办事项
---

## 添加一条待办

顶部一行式输入框，从左到右：

- **标题**：输入后按回车立即保存；
- **优先级**：高 / 中 / 低，默认中；
- **截止日期**：可选日期选择器；
- **标签**：逗号分隔可填多个，如 `工作,周报`。

只填标题回车也完全可用，其余字段之后随时补。

## 筛选与查找

- 状态分段：未完成 / 已完成 / 全部；
- 优先级分段：全部 / 高 / 中 / 低；
- 右侧搜索框按关键词实时过滤（延迟 200ms 防抖）。

## 列表分组

待办以**卡片**形式展示，每条一张：卡片第一行是标题，第二行是元信息（优先级、截止日期、标签、来源），不再挤在同一行，长标题和多个标签都能完整看到。

卡片按截止日期自动分组：**已逾期 → 今天 → 未来 3 天 → 稍后 → 无日期 → 已完成**。逾期分组标红，顶部的逾期横幅会给出数量提醒；逾期条目的日期同样标红，今天到期的加粗强调，高优先级在卡片上有红色「高」标记。

## 完成与撤销

点待办左侧的**圆钮**完成；完成后再点一次重新打开。已完成条目标题置灰加删除线，归入「已完成」分组。

## 行内编辑

直接**点待办标题**进入编辑：修改标题与截止日期，`Enter` 保存，`Esc` 取消。

## 删除与撤销

行尾 `×` 删除，删除后左下角 Toast 提供**撤销**，点击即按原内容重建。

## 来源标记

卡片底部的小标签标明来源：**AI**（通过 MCP 由 AI 创建）、**计划**（由学习计划自动生成）；App 内手动创建的不标记。
