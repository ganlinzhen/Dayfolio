## 页面操作区

顶部是「未完成 / 已完成 / 全部」、标题或备注搜索和「记录」入口。下方依次为新增输入区、日期筛选、优先级与分类筛选，以及当前结果数量。采用细线列表，标题、备注摘要和元信息分层展示，长标题完整换行。

## 添加一条待办

点击「接下来要做什么？」展开排期表单。输入标题后填写安排，再按回车或点击「添加待办」：

- **快捷日期**：今天、明天、暂不安排；「暂不安排」清空日期和时段。
- **时间安排**：默认时间段，须填写开始时间，结束未知可留空。跨午夜设置结束日期，结束须晚于开始。仅确定日期时切换为「仅日期」。
- **优先级**：高 / 中 / 低，默认中。
- **备注与标签**：按需展开，标签用中英文逗号分隔。

保存中禁用重复提交，失败保留草稿并显示原因。`Esc` 收起并保留草稿；「取消新增」清空本次草稿。中文输入法选词回车不会添加。未在其他输入框中输入时，按 `N` 聚焦新增、`/` 聚焦搜索。

## 筛选与查找

- 状态：未完成 / 已完成 / 全部；
- 日期：全部日期、今天、已逾期、未来 7 天、无日期；未来 7 天包含今天及后六天，跨日事项按日期重叠纳入；
- 优先级与分类：与状态、日期、搜索叠加；分类与日历保持一致，隐藏日历分类不影响待办查询；
- 搜索：匹配标题或备注，200ms 防抖；`Esc` 清空并退出搜索；
- 「清除筛选」清空日期、关键词、优先级与分类，保留状态选择。

日期按钮计数基于当前状态、优先级、分类与关键词匹配的记录，结果数量反映当前日期筛选。当前业务入口最多返回 500 条；达到上限时明确提示，日期筛选、计数与排序仅针对已返回记录。分类在其他入口删除后自动恢复全部分类。

## 列表分组与排序

固定按 **已逾期 → 今天 → 未来 3 天 → 稍后 → 无日期 → 已完成** 分组。点击分组名称可收起、展开。「组内排序」支持时间先后、优先级、最近添加，保持日期分组顺序；时间先后将同日的明确时刻放在仅日期事项前面。

有明确结束的待办在结束后逾期；仅开始或仅日期的待办在相应日期结束后逾期。跨日安排按结束日期判断。固定时刻使用统一显示时区，浮动安排保持原日期和钟点。逾期日期标红，高优先级附文字标记。分类与同名标签只展示一次，自动关联标签隐藏但原数据保留。

## 完成与撤销

点击左侧圆钮完成，再点可重新打开。成功提示提供「撤销」；完成记录由共用业务服务维护。已完成标题显示删除线，归入「已完成」。操作失败时保留条目并显示原因。

## 行内编辑

点击标题展开编辑，支持标题、排期、优先级、备注和标签。「保存待办」或 `⌘/Ctrl + Enter` 保存，标题输入框也支持回车保存；`Esc` 或「取消」放弃修改。备注中的普通回车换行。

仅修改备注、标签或优先级不会提交排期或停止来源跟随。修改标题或排期沿用个人接管规则。保存校验记录修订号，并发修改时保留草稿并提示，可选择「载入最新内容（放弃草稿）」重新编辑。

## 删除与撤销

行尾 `×` 展开确认，点击「确认删除」后执行；删除提示短暂提供「撤销」，按原内容重建独立待办。已完成待办会重新标记完成，形成新的完成时间；原计划、工具或事件订阅关联不会恢复。撤销失败时显示原因，不静默丢失操作。

## 查看打卡记录

点击待办页头部「记录」进入打卡记录页，查看精确到秒的记录时间、连续天数与活跃情况。点击「返回待办」回到列表，筛选条件会保留。侧栏不再单独展示「打卡」。

## 来源标记

卡片底部的小标签标明来源：**AI**（通过 MCP 由 AI 创建）、**计划**（由学习计划自动生成）；App 内手动创建的不标记。


## 完成记录与活跃情况

### 什么会记为打卡

两类动作会自动写入打卡记录，无需手动整理：

- **完成待办**：在任意面板勾选待办；
- **计划条目打卡**：完成学习计划里的某条安排。

> 手动「每日打卡」入口已于 2026-10-14（v0.15.0）移除（今日页、打卡面板与菜单栏托盘不再提供）；历史「每日」记录保留展示，连续天数与热力不受影响。

### 打卡面板看什么

- 活跃区显示**连续打卡天数**（streak），下方一行 28 个热力点展示近四周活跃情况，悬停可看具体日期；
- 热力点下方给出**近 7 天 / 近 30 天活跃天数**，累计打卡次数在顶部显示。

### 最近记录

下方按时间以细线分隔的列表行列出最近 60 条打卡：主行是来源徽标（区分**每日（历史）/ 待办 / 计划**）与内容描述，元信息行显示实际记录时间（精确到秒）与备注；补记日期与实际记录日期不同时，另外标注「补记 YYYY-MM-DD」。重复打卡保留首次记录时间，仅刷新备注。

### 小技巧

- 断签只影响连续天数，历史记录都在；
- 想让打卡链不断，完成任意一条到期待办或学习条目即可。

## 外部事件关联的待办

HTML 工具的「加入待办」保存本次内容快照，与下述事件订阅分别处理。工具页面的批量预览可勾选事项、跳过已有记录，并显示待办分类；首次确认添加新事项时才创建或复用分类，取消预览不创建。添加后可在「待办」按分类筛选并正常编辑、完成或删除，日历中可单独控制分类显示。重复添加不覆盖个人修改、分类或完成状态，也不恢复已移除记录；不会自动同步来源改期或新增比赛。

关联事件默认跟随来源标题与排期。有效修改标题或排期后转为手动安排；改备注、标签或优先级不会停止跟随。来源取消时，仍跟随的未完成待办清空排期并保留；手动安排保留个人时间，并显示「来源已取消」。时间待定显示相应提示。已完成记录不会因来源更新重新打开。

当前接口支持查询订阅、取消订阅和按双修订恢复跟随；也可以从今日页日历点击订阅待办进入来源详情。日历更多菜单中可管理分类，工具箱通过「导入 HTML」添加页面，不再安装运行时工具包。

日历中点击「新建日程」旁的更多按钮 →「管理分类」，可以编辑共用分类的名称和颜色，或确认删除自定义分类。删除分类保留待办与完成记录，将其归入基础待办；学习与订阅仍按真实关联归类。隐藏分类只影响日历，待办列表仍可查询。

HTML 工具事项可从「来源详情」查看持续关注状态和最新来源。标题或排期手动修改后转为个人安排，后续资料更新不覆盖；备注、标签、优先级独立保留。已完成记录不自动改动或重开，删除后不自动恢复。确认恢复跟随会用最新来源替换标题与时间；停止关注会保留当前待办。
