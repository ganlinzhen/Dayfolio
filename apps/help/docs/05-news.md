从侧边栏「新闻」进入，入口位于「待办」下方、「学习」上方。

## 管理长期采集提示词

新闻列表点击「AI 采集」，在「采集提示词」中编辑关注方向、筛选标准、摘要格式及专题要求，点击「保存提示词」。同时可调整最多收录条数（1~11）与时间范围（1~720 小时）。未保存时显示提示，并禁止启动新的采集；可撤销修改。多窗口冲突时重新加载已保存版本再编辑。

默认要求为：国际 3–5 条、国内 3–5 条独立新闻，加 1 条 AI 专题简报（含 3–5 则 AI 消息）；总计 7–11 条。每则新闻都有摘要、原始链接和真实发布时间。可自由修改提示词来调整内容；数量要求是助手的检索目标，来源不足时如实说明缺口。

采集开始时保存当前要求的快照；修改长期要求仅影响下次采集。提示词保存在 App 与 MCP 共用的 SQLite 中，重启仍保留。保存提示词本身不会启动采集。

## 两种更新方式

- **在 App 直接调用 Agent**：先到侧边栏「设置 → 配置 Agent」，选择本机已安装、已登录的 Codex、Claude Code 或 Gemini CLI，检查连接并保存。回到新闻页点击「更新今日新闻」，后台立即调用所选 Agent 搜索、核实、保存，结果自动刷新。不需要打开 Codex App。
- **在 Agent 对话中更新**：在已接入 Dayfolio 的 Agent 对话中说「按保存要求更新今日新闻」。助手读取当前采集要求，在本次对话中连续完成搜索、核实、入库和回读。该方式不依赖 App 后台 Agent 的选择。

新闻页不再提供「新建采集」或「按已保存提示词创建采集」等待下一次 AI 会话的入口。内部任务记录用于预算、去重、停止与失败重试；旧记录与新闻保留。搜索、认证或联网失败时如实显示失败，不能当作「没有新闻」完成。

App 不抓 RSS/X，不管理新闻源密钥；网页核实由 Agent 执行。本版本没有增加每日定时调度。外部自动任务每次执行前仍须读取最新保存要求，并在同次执行中完成采集。

## 界面：列表页、详情页与 AI 采集页

- **列表页**：顶部一行包含全部 / 未读 / 收藏、库内搜索（本地查询，不联网）、「更新今日新闻」与「AI 采集」入口。新闻始终按发布时间倒序，滚动到底部自动加载更多；窗口重新聚焦及后台采集进度变化时自动同步本地库。新闻发布时间按北京时间显示列表占满窗口剩余高度、只在内部滚动；鼠标悬停某条新闻时右侧出现删除按钮。
- **AI 采集页**：保存采集要求、启动后台更新并查看采集记录；「配置 Agent」跳转设置。每个记录显示状态（未完成 / 核实中 / 已完成 / 已取消）、已收录篇数与上限、要求和时间范围；有结果时点「查看 N 篇」回到列表并只看该次采集，待执行请求可取消。认领次数、租约、MCP 等执行协议不在卡片上展示，需要排查时再看本页说明或 MCP 工具。
- **详情页**：点列表新闻进入独立详情页，查看摘要并直接内嵌阅读原始来源页面；原文区占满详情页剩余高度，可重新加载、切换应用内全屏（占满侧边栏右侧内容区）或改用系统浏览器打开。内嵌原文只在打开详情时按需加载，使用隔离的非持久会话，禁用 Node、弹窗与系统权限，内容不进入 Dayfolio 数据库。若站点加载失败或不支持内嵌，仍可用「打开原文」兜底。点「返回列表」回到原来的筛选、搜索和滚动位置。宽窗与窄窗采用同一套页面切换方式。

## 内容形态：URL 内嵌与本地快照

新闻详情页有三种内容形态，由 AI 助手提交时决定：

- **专题简报**（`content_kind=brief`）：列表显示一条新闻并标注内含消息数。打开详情阅读总体看点、逐则标题和摘要，点击各自的「阅读来源」用系统浏览器打开对应原始链接。简报每则来源与时间均校验，整份简报只占一个采集名额；内容保存在数据库，不依赖远程网页加载。
- **URL 内嵌**（默认）：来源是可以正常打开的网页时，详情页直接内嵌来源页面。
- **本地快照**（`content_kind=html`）：**X（Twitter）等站点不允许内嵌**，助手提交这类新闻时会把核实到的原文（作者、发布时间、正文、配图、原帖链接）整理成一份自包含 HTML 快照，随新闻一起保存在数据库旁的 `news/` 目录；详情页改用「本地快照」区展示这份快照，列表与详情页会标注「快照」。快照在保存前会自动剥离脚本与危险协议（保留配图的 https 外链）；仍保留「打开原文」按钮跳转到原始链接。

删除带快照的新闻时，快照文件随行删除；快照文件意外缺失时详情页会提示改用「打开原文」。

## 硬校验规则（core 层，App 与 MCP 共用）

- **任务创建**（后台执行与 MCP 工具同一实现）：主题必填 ≤200 字、临时补充规则 ≤2000 字（结合长期提示词后 ≤14000 字）、上限 1~11、时间窗 1~720 小时；未终结任务最多 50 个。
- **预算**：每任务累计最多 11 条「新入库」（`max_items` 可设更小，上限 11；**跨批次与重试累计**，重复提交无法绕过）；**历史新闻展示不受任务条数限制**。
- **提交校验**：任务须被持有有效 `claim_token` 的会话认领且租约未过期；每条标题/摘要非空、来源链接必须是 http(s) 公开页面（拒绝本地/内网/javascript: 等）、发布时间不得在未来且须在任务时间窗内（默认近 24 小时）；可选的本地 HTML 快照非空且不超过 100 万字符，入库前自动消毒（剥离脚本与危险协议）。
- **简报校验**：简报须有总览和 1~20 则新闻，每则均附有效来源、摘要和时间；外层来源及时间使用首则新闻的值。简报不能同时附 HTML。简报子条目参与跨批次去重与删除指纹，但不单独入库。
- **去重**：同来源链接（规范 URL）或同事件（归一化标题完全一致）一律拒绝，批内与库内都查；**任何一条不合法即整批拒绝**，绝不部分入库。
- **数据安全**：旧新闻与收藏（含旧版 X/知乎/HN/RSS 历史）全部保留，只读展示；`news` 表新增列不改动历史行。

## 删除新闻（不可恢复）

列表悬停出现的删除按钮或详情页的「删除」按钮都可删除单条新闻。删除前会弹确认框说明后果；确认后**不可恢复**：

- 正文与收藏、已读状态一并移除；本地快照文件随行删除；若正开着这条新闻的详情页，会自动返回列表并保持原有筛选与滚动位置。
- 引用这条新闻的自媒体选题/素材**不会被删**：它们是独立成果，保留各自的来源快照（标题与链接），只解除指向已删新闻的失效引用。
- 只保留一条**最小哈希去重指纹**（不含正文、标题或链接明文，无法反推内容）：之后 AI 助手对**同一链接或同一事件**的新闻提交会被直接拒绝，防止删掉的内容立刻回流。
- AI 采集任务的累计收录名额**不因删除返还**：例如任务上限 10 条、已收录 10 条，删掉 3 条后该任务也不能再收录新的。
- 重复删除同一条（或多端同时删）是安全的：第二次返回「未删除」，不报错。

经 MCP 删除：对助手说「删掉这条新闻」并确认后，助手调用 `delete_news_item`（同一套事务规则；助手必须先复述标题并得到你的确认，绝不允许批量删除或未经确认调用）。

## 让 AI 助手管理新闻

`get_news_collection_settings` / `update_news_collection_settings`（读写长期采集提示词）、`create_news_task`（建任务，`use_collection_prompt=true` 使用最新已保存要求）、`list_news_tasks`（看任务与进度）、`claim_news_task`（认领执行）、`submit_news_items`（核实后提交；X 等无法内嵌的来源可附 `html` 本地快照）、`complete_news_task` / `release_news_task`（完成/释放）、`cancel_news_task`（取消，需用户同意）、`list_news`（库内查询，可按任务/来源/关键词/收藏过滤）、`read_news_html`（回读本地快照核对）、`mark_news_read` / `mark_news_starred` / `mark_all_news_read`（阅读状态，与 App 共享）。

> 旧版抓取工具（`fetch_news`、RSS 源与话题管理）已移除；`npm run news:fetch` 命令行入口同步移除。


## 本体浏览

新闻任务与新闻条目均已纳入数据面板。任务的认领令牌仅通过认领工具返回；通用查询、搜索和 JSON 导出不包含令牌。新闻仍必须按租约和来源规则经任务提交，不能直接创建新闻对象绕过。

## 后台进度、停止与重试

采集页显示真实进度，有结果时可点记录卡片的「查看 N 篇」。重复启动复用活动运行；「停止采集」停止本次进程并保留已收录新闻。「重试本次采集」或未完成记录上的「重试采集」接续剩余预算，不重置已收录数量。

后台一次只执行一条新闻任务，内部队列最多 10 条，每次最长 12 分钟。关闭窗口后菜单栏常驻仍可采集；彻底退出 App 会停止执行。再次启动会将原宿主已退出的运行标为中断，可手动重试。

连接配置统一在「设置 → 配置 Agent」维护。Dayfolio 不携带 Codex 或其他 Agent 运行时，不替换全局 CLI，不保存账户密钥；使用相应 CLI 的登录与额度。后台使用独立工作目录，仅开放网页搜索、原文读取和本次任务的三个 MCP 工具，不开放终端命令或其他业务写入。CLI 的模型、搜索权限、账户额度与网络仍需可用；Gemini 的连接检查只确认 CLI 可启动，登录在实际任务中验证。

进程正常退出并且业务任务完成后才显示成功；已完成检索但无合格新闻可以 0 条完成，认证、网络或搜索不可用则显示失败。MCP 的 `list_news_agent_runs` 可查进度，`cancel_news_agent_run` 可按用户要求停止；对话中更新直接沿用认领、核实、提交与完成流程。
