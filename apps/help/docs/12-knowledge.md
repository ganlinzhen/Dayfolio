## 页面操作区

列表顶部显示知识库选择、笔记数量、扫描时间和「重新扫描」。「管理知识库」展开后可查看目录路径、注册新库或移除当前库。下一行提供分区切换、层级下拉和搜索；笔记行分开显示标题、分类状态和路径，阅读页保留紧凑的笔记名称与操作。

## 知识库是什么关系

「知识库」页把你的 Obsidian vault（如 `~/Desktop/knowledge-base`）以**只读**方式接进 Dayfolio：**列表页**浏览/搜索索引，点开一篇进入**阅读页**读卡片原文、看链接与反链、维护概念关联（左上角「返回笔记列表」随时回列表，返回后会高亮刚才读过的那篇；阅读页里点链接或被引用卡会直接跳到目标卡片）。**内容唯一来源永远是磁盘上的 Markdown 文件**——Dayfolio 里的索引只是可重建的缓存；你在 Obsidian 里的任何修改都优先，重新扫描即可刷新。

只读红线：

- **绝不写入 vault**：不改文件、不改 frontmatter、不触发 Git 提交；学习卡草稿仍走「学习计划」页的导出（也只能导到 vault 外目录）；
- 附件图片在阅读视图中**不加载**（显示占位），正文经安全渲染后放在无脚本的沙箱视图中——vault 里的脚本、事件属性、危险协议不可能执行；
- 索引范围默认 `knowledge/moc/`（导航）、`knowledge/resources/`（正式卡，按道/法/术/器分层）、`knowledge/inbox-cards/`（待审草稿）；`raw/` 原料区默认不索引，需要时在库设置中开启。

## 注册与扫描

首次进入点「注册知识库目录」选择 vault 根目录，注册后自动首次扫描。之后随时点「重新扫描」做**增量刷新**：新增/修改的卡片入索引；磁盘上消失的卡片标记**缺失**（记录与关联历史保留，不会静默删除）；内容没变只被 touch 过的文件不重复处理。若阅读时发现文件在扫描后被改过，会提示「索引过期」——内容显示的是最新原文，重扫即可对齐。

## 浏览、搜索与阅读

- 列表页过滤条：分区（MOC / 正式卡 / 待审 / 原料）、层级（道法术器）、关键词（搜标题、路径与正文）；
- 笔记行显示标题、路径、状态（active/draft 等）与缺失标记，点击进入阅读页；
- 阅读页：正文来自磁盘**实时读取**（不是索引副本），显示来源路径、大小与状态；正文可点「全屏」占满侧边栏右侧内容区，「在 Finder 中显示」定位原文件；若提示「索引过期」，可在提示条上直接点「立即重新扫描」；
- `[[双链]]` 解析为可点的链接（精确路径优先，同名多义时列出候选，找不到标**断链**）；「被引用」列出谁链接到当前卡。两者点击后都直接在阅读页内切换到目标卡片。

## 关联学习概念（knowledge_key）

每张卡可关联一个或多个**学习概念**（与学习计划条目、课程使用的 knowledge_key 同一命名空间）：在阅读页输入概念键（如 `ts/generics`）回车即关联。关联关系只存在 Dayfolio 数据库——**vault 文件不会有任何变化**。一个概念可关联多张卡，一张卡也可被多个概念引用；复习与课程据此找到对应卡片，AI 客户端也能通过 `list_concept_links` 查询。

## 复习与转正（沿用既有流程）

- **复习**：继续用学习计划的复习任务与打卡；打开卡片阅读后自行闭卷复述，掌握证据仍走「学习闭环」的测评（阅读次数不算掌握）；
- **待审转正**：学习卡草稿在 Obsidian 里按正式模板改写、移动到 `resources/` 并设 `status: active`——重新扫描后它就是一张正式卡，再手动关联概念即可。Dayfolio 不提供「一键转正」（写入 vault 的能力暂不开放）。

## 让 AI 帮你

- 「注册/扫描我的知识库」（`register_vault` / `scan_vault`）
- 「搜一下我记过关于 X 的卡片」（`search_vault_notes` / `list_vault_notes`）
- 「读一下那张价值公式卡」（`get_vault_note`）
- 「把这个概念关联到那张卡」（`link_concept_note` / `unlink_concept_note` / `list_concept_links`）


## 本体浏览

知识库注册、笔记索引和知识键关联均可统一浏览。索引只由扫描服务维护，外部 Markdown 仍是正文唯一来源；移除注册不删除笔记。知识键仍按原字符串和学习上下文使用，不自动合并掌握度。
