## 是什么

`preview-isolated` 是一个**一次性沙盒预览**：用已构建的应用产物在一个全新的临时目录里启动 TodoDesk（独立 HOME / 数据库 / 用户数据 / 课程与工具资产根），并预置一套标注「演示」的四模块闭环数据。退出后临时目录自动清理，**真实数据零触碰**。

## 用法

```bash
cd <仓库根目录> && node apps/desktop/scripts/preview-isolated.mjs
```

前置：macOS、Node 22.13+ 或 24.x（推荐 24.x），在仓库根目录运行 `npm ci`、`npm run build:desktop`。完整桌面构建会为 Electron 重建 SQLite 原生模块，脚本会检查缺失产物并提示。

## 开发者干净环境验收

在仓库根目录运行 `npm run verify:clean`：按 Git 跟踪文件与未忽略的新文件复制当前源码到临时目录，使用独立 HOME、数据库和用户数据，从 `npm ci` 开始执行测试、类型检查、帮助同步、插件验收、桌面构建、演示界面冒烟与打包签名验证。不会提交或推送，也不会替换已安装的应用。临时日志与报告路径会在终端输出，便于排查。

## 演示内容（打开即看）

- **新闻**：旧闻 2 条（含 1 收藏）· 已完成任务（2 条 agent 新闻）· 待执行任务——你也可以在面板亲手「新建任务」，体会「待执行 → 等待助手认领」的诚实语义。
- **知识库**：「演示知识库」vault 已注册并扫描（3 篇笔记、wikilink 互联、反链可跳）。它是临时目录里的**测试 vault**，只建只读索引，绝不写你的真实 Obsidian。
- **自媒体**：选题（来源关联演示新闻）→ 母稿 → 小红书/公众号双版本。小红书版已「审核通过→排期→手动发布占位→指标 1500/120」；公众号版**停在「待人工审核」**，等你亲自通过或拒绝。发布均为占位记录，不涉及任何真实平台登录或发布。
- **课程**：内置「TodoDesk 上手之旅」演示样课（自包含，不依赖任何外部资产）绑定「【演示】TodoDesk 五天上手计划」；**样课未确认**——阅读/确认入口留给你体验。入口在「学习计划」页对应计划的「关联课程」区。

## 退出与清理

关闭预览窗口后应用仍驻留菜单栏托盘（macOS 行为）——请从**托盘菜单「退出」**或 Dock 右键退出，也可直接在终端 **Ctrl+C**。退出码：正常退出透传 Electron 真实退出码（被信号杀死=1、启动失败=2）；隔离/前置断言失败=2；演示数据构建或播种失败=3。**所有正常/异常退出都会先清理临时目录再退出**（对脚本本身 `kill -9` 除外）。想保留现场检查：`KEEP=1` 前缀运行，检查后手动删除。

## 边界

- 启动前硬断言所有路径位于同一新建临时目录：命中真实 HOME、Application Support、真实 knowledge-base 或真实课程资产路径即拒绝运行。
- 沙盒里的确认/审核/发布/掌握都是演示数据上的模拟，不代表也不改变任何真实状态；真实库的版本迁移与生产备份须另行获得批准后才执行。
