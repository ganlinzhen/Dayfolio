## 页面操作区

数据首页头部仅显示对象类型数量和「刷新数据」。进入类型详情后，头部显示返回入口、紧凑的类型名称、API 名称和刷新操作，不重复显示栏目大标题。

「数据」面板是整个 App 的数据中枢：用**本体**的方式统一描述和管理所有数据——类似「这个应用里有哪些种类的数据、它们之间有什么关系、可以对它们做什么操作」。

## 数据首页

首页从上到下依次展示三个区块，不需要切换视图：

| 区块 | 作用 |
| --- | --- |
| 总览 | 数据库大小、已有对象总数、对象类型/关系/动作数量、迁移版本，以及数据库和工具文件目录 |
| 对象类型 | 显示所有对象类型的名称、apiName、属性数、已有对象数量及来源；点击名称或「查看详情」进入类型详情，可新建类型 |
| 维护 | 备份数据库、导出 JSON、完整性体检、VACUUM 压缩 |

右上角「刷新数据」重新读取类型定义和存储统计。返回首页会保留原来的滚动位置。

## 对象类型详情

详情页顶部显示类型说明、物理表名、主键、标题属性和来源，下方按页签展示：

- **表结构**：全部字段、数据类型、主键/标题标记、是否可空、枚举值、索引和来源；可添加属性、删除自定义属性或删除自定义类型。
- **关系**：仅展示当前类型参与的关系（含由它承载的中间表关系），查看两端类型、基数、外键/中间表/多态引用与方向命名；可新建关系或删除自定义关系。
- **动作**：仅展示作用于当前类型的内置动作或写规则引用当前类型/关系的自定义动作；「查看定义」展开说明、参数、默认值与执行规则，可启停、执行或新建动作；执行会真实修改数据。
- **已有对象**：当前类型的实例数据，支持搜索、分页和点击实例查看详情。虚拟类型没有独立物理表，此页显示说明。

### 筛选、排序与分组

在“已有对象”中展开“筛选、排序与分组”：

- 点击“添加条件”，选择字段、比较方式和值。可同时满足多个条件，也可满足其中任意条件；列表值用逗号分隔，空值使用“为空／不为空”。
- 可按已注册的关系筛选“有匹配对象／无匹配对象”。历史引用的目标已经删除时，不算实际存在的关联对象，详情仍保留历史引用说明。
- 对象列表可按字段升序或降序排列，空值排在最后，相同值用主键补充排序。
- 切换为“分组统计”，最多选择两个分组字段，并选择数量、合计、平均、最小或最大指标；不选分组字段时统计整体。界面分别显示匹配对象数和分组数。
- 点击“应用查询”后生效；“重置查询”清除条件、排序和分组，保留上方搜索文本。搜索和结构化条件共同生效。

查询只读取现有数据，不触发联网采集或 AI 生成。JSON 属性暂不支持普通比较、排序或分组；时间字段会按其声明的日期、本地时间或带时区时刻校验。非法存量值或超出安全数值范围的聚合会明确报错。普通分页在并发增删记录时可能移动，不代表跨页固定快照。

AI 查询较多记录时可在 v1 的 page 中选择 `mode="cursor"`，使用返回的 nextCursor 继续读取。游标绑定查询条件和模型定义，可跨 App/MCP 或重连继续；修改条件、模型或篡改游标会被拒绝，需要重新开始。它减少插入造成的翻页位移，但不承诺并发改动期间的跨页固定快照。分组统计仍使用普通分页。

类型管理表格和实例表格占满可用宽度，宽表在容器内横向滚动。页签可用左右方向键切换，也可用 Home/End 跳到首尾。点击「返回数据首页」回到类型列表。

## 本体三要素

- **对象类型**：一类数据的结构（属性、主键、标题属性）。系统内置类型覆盖待办、计划、打卡、新闻及任务、工具、课程与讲义、知识库索引、创作选题与内容、平台版本、素材、排期、指标和学习记录；你可以创建自己的类型（如「书」「笔记」），会自动建表；
- **链接类型**：两个对象类型之间的关系。一对多用外键属性承载，多对多用一个中间表对象承载。内置链接描述了计划→条目、待办→打卡等关系；
- **动作类型**：一组「参数 + 写规则」的可执行操作。内置动作绑定共用业务命令（完成待办会联动打卡）；自定义动作由你拼装规则：创建/修改/删除对象、建立/解除链接，执行时在同一事务内完成，要么全成要么全回滚。

## 管理规则

### 基础写入动作

新建自定义类型时，默认同时生成“新增、编辑、删除”基础动作；也可以关闭生成，之后自行定义写入动作。已有自定义类型会补齐基础动作，用户已有动作不被覆盖。

在“已有对象”点击“新增对象”，按字段填写后保存。实例详情的动作区可执行基础编辑或删除；可选字段的“不设置／保持原值”和“设为空值”分别表示保留字段与清空字段。删除仍受关系约束，并需要确认不可恢复的范围。

系统业务字段继续使用原业务动作；只有允许的用户扩展字段有对应编辑动作。建立和解除可写关系也有基础动作，不能用编辑字段直接换绑关系。

基础动作可停用，停用后 App 保存、旧通用 MCP CRUD 和通用动作执行都会拒绝相同行为。基础动作不能单独删除；删除所属类型或关系时自动清理。字段变更更新基础动作的输入格式，并保留动作名称和启停状态。用户另外定义的独立动作按自身定义执行，停用基础动作不代表停用该类型所有业务行为。

- **系统业务类型**：可以**追加可空属性**（只读索引、记录及历史类型不允许新增扩展字段）（自动加列），内置属性与类型本身受保护不可删改；
- **自定义类型**：完全可管理——加属性、删属性（连同该列数据）、删除整个类型（需输入 apiName 确认，表与数据一并删除）；
- 有链接或动作引用的对象类型/属性，需要先删掉引用方才能删除；
- 内置动作不可删除，但可以**停用**；停用后专用 MCP、业务面板与通用动作入口均拒绝执行。组合操作需要执行被停用动作时整体拒绝。

## 对象浏览与运行动作

在「数据 → 对象类型 → 具体类型 → 已有对象」中搜索、翻页，点实例名称或任意一行打开详情，详情占用主要内容区；点击「返回对象列表」会保留搜索与分页：

- **属性**：该对象的全部字段值；
- **链接**：按关系方向分组显示总数，支持加载更多，两个方向都能浏览多对多关系；点击对象跳转详情，历史目标已删除时保留引用并说明。自定义关系与内容—素材关联可建立或解除；其他系统关系使用业务面板操作。
- **运行动作**：选择一个动作并填参数，可直接对当前对象执行（按动作的对象参数绑定自动预填当前对象，对象参数可以通过标题搜索选择）。

学习计划可选内置「删除学习计划」（`delete_study_plan`）动作：`id` 自动预填，`delete_todos` 默认 `true`，删除计划、条目、相关打卡及本计划独占的自动生成待办；填 `false` 保留待办。执行前会再次确认范围，不可恢复。手工待办与其他计划共用的待办会保留；旧版本的历史残留不会自动清理。

## 维护操作

- **备份数据库**：使用 SQLite 在线备份（`VACUUM INTO`），备份期间不影响 App 与 MCP 的正常读写，产物在 `userData/Backups/`；
- **导出 JSON**：类型元数据 + 全部实例数据导出为一个 JSON 文件，适合归档或迁移；
- **运行体检**：完整性检查（integrity_check）与外键一致性检查；
- **压缩主库**：VACUUM 回收空间。

## MCP 联动

数据面板里创建的类型与动作对 AI 同样可用，MCP 提供本体工具（详见「MCP 与 AI 接入」）：

- **查询**：`list_object_types`（全部类型/链接/动作定义）、`query_objects`（按类型查实例）、`get_object`（单对象详情含链接关系）；
- **统一查询合同**：`get_query_contract` 查看字段能力、日期语义和限额；`query_objects` 的 `query` 参数支持版本化查询，`aggregate_objects` 提供分组统计，`query_related_objects` 分页读取实际存在的对端对象。新合同将 JSON 返回为结构化值，旧调用保持原返回结构；新旧参数不得混用。
- **实例 CRUD**：`create_object` / `delete_object` 仅操作自定义对象；`update_object` 可更新自定义对象或允许的系统用户扩展字段。这些旧工具会适配到对应基础动作，保留原返回结构；基础动作停用时同样拒绝。系统内置字段必须使用业务动作；混合字段修改整体拒绝。
- **类型管理**：`create_object_type` / `update_object_type` / `delete_object_type`、`create_link_type` / `delete_link_type`、`create_action_type` / `update_action_type` / `delete_action_type`；
- **执行**：`invoke_action`（业务命令或自定义动作）；自定义声明式动作在单个数据库事务内执行，含文件操作的内置命令使用各自的业务恢复规则。

你自定义了一个「记读书」动作后，直接对 AI 说「帮我记一笔读书」即可；也可以让 AI 自己建类型——「帮我建一个读书笔记类型，要书名/评分/心得字段」。


## 统一写入与关系规则

系统对象标注「业务动作」或「只读记录／索引」，自定义对象支持通用读写。对象详情中的「用户扩展字段」可单独保存；内置字段的变更走对应业务动作。知识库笔记正文继续以磁盘 Markdown 为唯一来源，通用接口不能改写索引或笔记。

对象类型列表将旧新闻话题放在「历史数据（只读）」中。新闻任务的认领令牌只通过认领工具返回，不出现在对象详情、搜索或普通 JSON 导出中。

自定义关系创建时检查现有数据、目标存在与基数：一对一不允许同一目标被重复关联；多对多二元组唯一。默认删除目标会被引用阻止，可选择「解除引用」，但承载字段必须可空。自定义关系不支持级联删除对端实体；多对多端点删除只清理关联行。重复建立／解除同一关系幂等，换绑必须先解除旧关系，必填关联不能单独解除。

历史学习证据保留原引用；删除计划不会抹掉学习会话、测评及调整记录。绑定该计划的课程仍受原完整性校验约束，不能通过删除计划绕过校验。

旧自定义动作若直接写系统业务字段，会显示「需复核」并拒绝执行；旧关系存在冲突时保留数据并暂停相关写入，维护体检显示待修复关系。升级不会自动清理这些历史数据。

样课确认、平台版本审核须在原课程／创作面板人工操作，通用动作和 AI 不能代替。关系的分页与操作分别由 `list_object_links`、`create_link`、`delete_link` 提供。
