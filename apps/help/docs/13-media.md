## 页面操作区

顶部直接显示「概览 / 选题 / 内容 / 素材 / 日历 / 复盘」切换，不再重复显示「自媒体」大标题和流程介绍。内容详情保留紧凑的具体内容名称。

## 六步工作流

「自媒体」页是一个**纯本地**的内容生产工作流：概览 → 选题 → 内容 → 素材 → 日历 → 复盘。

**红线：Dayfolio 不登录任何外部平台、不自动发布。**「排期」只是本地计划；真实发布动作由你在各平台手动完成，然后回到日历**回填**发布状态与作品链接；数据指标同样**手动录入**。平台版本的**人工审核**是必经关卡——AI 可以写稿，但每一条版本都须你在概览或内容页亲自「通过」后才能排期。

## 概览

一屏看清全局：已选用题、内容母稿数、**待人工审核版本**（可直接「通过/拒绝」）、已排期待发、近 30 天已发布、素材数。待审与未来排期两个清单都在这里，点标题直达。

## 选题（点子池）

随时把题目记下来（标题 + 角度），来源可**关联新闻**（从最近新闻中点选，自动快照标题与链接，不怕原新闻被清理）或知识卡片。状态流转：点子 → 已选用 → 已放弃（可恢复）。「建内容」一键从选题生成母稿并自动标记选用。

## 内容（一母稿多平台版本）

- **母稿**：内容的唯一上游。写好可「标记定稿」；
- **平台版本**：同一母稿为每个平台各建一个版本（小红书 / 公众号 / 抖音 / B 站 / 知乎 / 微博 / X 等，同一平台仅一个版本）。版本状态机：草稿 → **待审核** → 已通过 / 已拒绝；拒绝后可改稿重新提交；已通过的版本要改须先「撤回重编」；
- **排期**：对已通过的版本选日期排期；同一版本重复排期视为**改期**；已发布后不可改期；
- **素材挂载**：从素材库挑素材挂到内容上，导出素材包时一并带上；
- **复盘笔记**：发布后回填经验（什么标题/时间/封面有效）。

## 素材

金句、数据、图片说明、参考链接的仓库，来源同样可关联新闻/知识卡片（可追溯）。图片文件本身不入库，以说明文字记录；导出素材包时按说明列出。

## 日历（排期与发布回填）

按日期倒序查看全部排期。到期的条目：你手动发布后点「我已手动发布」并粘贴作品链接（可选）→ 状态变**已发布**；不发了可「取消」。已发布的条目到「复盘」录数据。

## 复盘（手动指标）

- **平台汇总**：按平台聚合发布数、阅读/播放、赞、评论、转发、收藏，可限定日期区间；
- **指标明细**：逐条录入（同一条同一天重复录入为**覆盖更新**），支持完播率等自定义数值；
- 内容级的经验总结写在该内容的「复盘笔记」里。

## 素材包导出

内容详情页「导出素材包」：选择一个**vault 外**目录，导出 `master.md`、各平台版本、素材及出处、排期记录与说明文件。目录约束在 core 层**硬拒绝**（不是提示）：位于任何已注册知识库内、内置默认保护根（`~/Desktop/knowledge-base`，**即使尚未注册**）或 `TODODESK_PROTECTED_DIRS` 环境变量指定目录内的目标一律报错；符号链接别名指向 vault 同样拦截。目标子目录已存在时拒绝导出（防覆盖）。

## 让 AI 帮你

- 「把这条新闻记成选题」（`add_media_topic`，来源自动快照）
- 「为这个选题写母稿和小红书/公众号版本」（`add_media_content` / `add_media_version`）——写完它会**提交人工审核**（`submit_media_version`），通过与否由你在 App 决定
- 「把我刚发的这条标记已发布，链接是 …」（`mark_media_published`）
- 「记录数据：阅读 1200 赞 88」（`add_media_metric`）
- 「这个月各平台表现怎么样」（`get_media_stats` / `get_media_overview`）
- 「把这篇的素材包导出到 ~/Desktop/exports」（`export_media_package`）


## 对象与关系联动

选题、母稿、平台版本、素材、排期和指标均可在数据面板浏览。内容与素材可以从任一端查看、分页和关联。审核通过／拒绝／撤回继续在创作面板人工完成，通用动作不能代替；删除内容或素材只清除关联，不删除另一端对象。
