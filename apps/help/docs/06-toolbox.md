---
title: 工具箱
description: 收纳 HTML 小工具：分类管理、自定义图标、应用内打开
---

工具箱用来收纳你自己收集或编写的 **HTML 小工具**（计算器、取色器、格式转换……）。所有工具在应用内打开，不会跳到浏览器。

## 工具列表

- 工具按**分类分组**展示，每个工具有一个图标和名称；
- **点击卡片**即可在应用内打开该工具，工具默认占满侧边栏右侧内容区；顶部「工具箱」返回列表；
- 鼠标悬停卡片，右上角浮现**编辑**（铅笔）与**删除**（垃圾桶）按钮；删除会连同文件一起移除，不可恢复。

## 新增工具

1. 点右上角**「新增工具」**；
2. 填写**名称**，挑选一个**图标**，选择**分类**（可不选，默认未分类）；
3. 选择 **HTML 文件**：入口 `.html` 必选；一并多选的 CSS / JS / 图片等资源会保存在同一目录，页面里用相对路径引用即可；
4. 点「添加」，卡片立即出现在列表里。

工具是自包含的单页应用时，一个 `.html` 文件就够了。

## 让 AI 代劳

接入 MCP 的 AI 客户端（见「MCP 与 AI 接入」）也可以操作工具箱：

- 「把 ~/Downloads/色板.html 加到工具箱」→ AI 用 `add_tool` 读本地文件装入；
- 「帮我写个倒计时小工具放进工具箱」→ AI 现场生成 HTML 直接装入（无需落盘临时文件）；
- 分类不存在时 AI 会自动创建；装入后切换到工具箱面板即可看到，与手动添加完全一致。

## 分类管理

点右上角**「管理分类」**：

- **新增**：底部输入名称后回车或点「添加」；
- **排序**：每行的上移 / 下移箭头调整顺序，列表按此顺序展示，点「完成」保存；
- **重命名**：点行内铅笔（或双击名称）；
- **删除**：删除分类不会删工具，其中的工具自动移入「未分类」。

## 数据存放

- 工具的登记信息存在应用数据库中；
- HTML 及配套文件存放在**数据库同目录**的 `tools/<工具id>/` 下（默认 `~/Library/Application Support/tododesk/tools/`），AI 通过 MCP 装入的工具也写在这里，可手动备份；
- 旧版本曾存放在 `~/Library/Application Support/tododesk-desktop/tools/`，升级后会自动迁移过来。
