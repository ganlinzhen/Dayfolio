## 页面操作区

顶部左侧直接显示「计划 / 课程」切换，右侧显示当前计划、草案或课程数量，不再重复显示「学习计划」大标题。计划详情保留紧凑的具体计划名称与进度；条目详情保留安排标题、日期、类型与状态，移除顶部重复信息和快捷导航；依次展示课件、评测、AI 检验与学习笔记，完成操作集中在底部。

顶部「上手课程」可直接打开随 App 提供的「Dayfolio 上手之旅」，无需先建计划。课程也收录在「课程」列表中；当前提供总览和第 1 天样课。

## 计划从哪里来

计划主要通过 **AI 创建**：在 zcode 里对 AI 说「为《某某课程》制定 14 天学习计划，每天 1 小时」，AI 调用 MCP 工具 `create_study_plan` 生成逐日安排，并**自动为每天生成关联待办**。App 内的「学习」面板负责查看与打卡。

走**学习闭环**（推荐，见「学习闭环」一节）时，AI 先生成**待确认草案**：面板列表顶部会出现草案卡片，展示逐日安排与「假设清单」（AI 缺省处理过的信息），由你**确认生成计划**或**取消草案**（取消不产生任何计划与待办）。

## 未排期专题草案（日期待定先存后排）

材料已到位但**还没定什么时候学**（比如一批专题文稿先存着）时，AI 用 `draft_study_topic` 保存**无日期专题草案**：只存主题大纲、知识点分解、材料来源和可选的**样课课程关联**（样课未确认也能关联）——**不排日程、不产待办、不占每日预算**。这类卡片在列表里标「未排期专题草案」，展示知识点大纲（名称/时长/前置依赖），等你给出**起始日期与每日预算**后再排期：

1. 点卡片上的**「排期…」**，填起始日期与每日预算（10~600 分钟）；
2. **「预览排期」**先做只读预览：逐日安排、依赖顺序（先修在前）、与其他**进行中计划**的**每日预算冲突**（既有占用 + 新排超出预算的日子）与**知识点重复**预警、透明规则假设——有预警会黄条逐条列出；
3. 你核对后点**「确认排期」**才真正落库（**服务端硬校验**：按当下状态重算超预算日期，与你预览时知晓的集合必须完全一致，预览后其他计划有变动会被拒并要求重新预览；重复提交幂等）；换起始日期或预算可以重新预览、重新排期；
4. 排期后的草案回到原有流程：展示逐日安排，由你**确认生成计划**（生成逐日条目与待办）或**取消草案**。**确认时服务端会再次硬校验**——点「确认生成计划」会先取**当下最新**的超预算日期，若仍有冲突会在弹窗里**逐日列出**并要求你显式同意（不同意可取消、改回调整起始日期/预算）；若你在弹窗停留期间其他进行中计划发生变动，确认会被服务端拒绝并提示原因，刷新后重新确认即可。绝不会跳过你自动默认同意。

排期前草案内容仍可由 AI 更新（大纲/知识点/材料/课程关联）；排期后内容锁定，调整走取消重建或计划调整建议。**样课确认门禁不变**：课程与计划的绑定仍以课程包导入为准；你在 App 阅读样课后，在对话中明确确认，由助手记录当前内容版本。

## 计划列表

每张计划卡片显示标题、日期范围、目标、安排完成数量、进度条与状态（进行中 / 已完成 / 已归档），另列「课件已读 / 评测已做 / 笔记已输出」的条目数。点卡片或按 Enter / 空格进入安排列表。课件阅读沿用现有已读记录，不代表已掌握；复制提示词不增加进度。

顶部切换到**「课程」页签**可浏览所有课程：课程没有独立的侧栏入口（学习入口只有「学习」一个），课程页集中列出所有课程，包括未绑定计划的课程，显示名称、状态与绑定关系；点击可在本面板内打开课程总览（见「课程」一章）。

## 计划详情与学习卡片

条目按日期分组，每项安排独立成卡片，展示完整安排、类型、预计用时、状态，以及课件、评测和笔记进度。今天的分组标注「今天」。卡片上不再提供完成圆钮或跳过按钮，点「进入学习」打开条目详情。

- **课件**：关联课程后按「计划第 N 个日期 = 课程第 N 天」对应。已生成课件在条目详情直接展示全文、核心概念和源码导读，支持全屏阅读；加载成功记为已读。缺失的天标为待生成，没有课程时标为未关联。同一天多项安排共享当天课件与自测。
- **评测**：自测题直接显示在详情的「评测」区，选择答案后点击「提交答案」保存并查看解析。未提交的选择不计入进度。课件自测全部题目提交过答案，或本条目有实际测评记录时，计入「评测已做」。只答了部分题会显示作答题数。AI 建议性反馈、自测作答与客观通过分开展示，做过评测不等于掌握。
- **笔记**：条目详情可输入自己的解释、例子和疑问，点「保存学习笔记」，无需填写学习用时。内容作为关联该条目的学习会话保存，App 与 MCP 共用。只有非空的学习输出计入笔记，纯用时或空白会话不计入。
- **完成安排**：在条目详情底部点「标记完成」「撤销完成」「跳过」或「恢复待办」，沿用关联待办与打卡联动。三项学习进度与完成状态分别记录，由你决定何时完成，不会因读过课件或复制提示词自动完成。

## AI 检验学习成果

计划详情与条目详情都有「AI 检验学习成果」。点击「复制提示词，去 AI 聊天」，将提示词粘贴到已连接 Dayfolio 的 AI 客户端：计划详情检验整个计划，条目详情只检验当前安排。复制成功会提示，可展开「查看提示词」核对内容。

提示词携带计划、条目、课程 ID 与对应天序，要求 AI 先读取最新安排、实际讲义、笔记与已有测评，再主动提出第一道问题。一次只问一个问题，等你回答后纠正理解，逐步进入应用与迁移题。没有读取能力时，AI 应请你粘贴材料，不凭标题编造课件。

结束时先核对笔记，再由 AI 经 MCP 保存学习会话与测评。学习用时可省略，仅在你主动提供时记录；建议性反馈标记为 `ai_suggestion`，不得冒充客观通过。你明确要求完成时才更新条目。按钮只复制提示词，不会自动打开外部客户端、启动对话或写入学习完成状态。切回 App 后同步最新进度。

## 关联课程的计划：每日摘要卡与「待生成」

课程导入时绑定计划，或确认带 `course_id` 的草案时自动关联课程后，详情页会有明显变化：

- 顶部出现**关联课程条**：课程标题、已生成天数，以及**「进入课程总览」**按钮（在本面板内打开该课程总览，返回时回到计划详情并恢复原滚动位置）；
- 每个日期组标注**「第 N 天」**徽标——计划第 N 个日期对应课程第 N 天；
- 已生成的天显示**每日摘要卡**（讲义标题、核心概念、本课 v1/v2 版本、时长、已读/可阅读状态），点击**直达当天完整讲义与自测**，读毕点「返回计划详情」原位回到这里；样课确认后不再附加「样课」标识，确认过期时恢复；
- 尚未生成的天明确显示**「讲义待生成」**：当天该按计划大纲做什么一目了然（在条目详情记录学习与完成），讲义待课程完整版生成后解锁（在 App 阅读样课后，回到对话确认并请求完整版）。

计划条目的打卡、进度与掌握徽标不受课程影响——两边互不干扰。

草案中的课程关联在确认生成正式计划时生效，单独保存或排期草案不绑定计划。如果旧版已确认的草案记录了课程，但两边仍显示未关联，可让助手重复调用 `confirm_study_plan_draft` 补齐关系；复用原计划和待办，保留学习进度。课程若已绑定其他计划则拒绝，不能借此改绑，也不会根据同名标题猜测关联。

## 学习记录 / 计划调整 / 知识卡片

学习闭环的计划详情底部提供会话、调整与知识卡片；条目详情也可直接保存学习笔记：

- **学习记录**：每次学习会话的时间、自己的解释、疑问与材料，按时间列出；
- **计划调整**：「查看调整建议」只做**预览**（漏做改期 / 薄弱补复习，附判定依据）；勾选后「应用选中」才写库（改期会同步待办截止日），点「取消」不做任何变更；
- **知识卡片**：「预览待审卡片」生成 Obsidian Markdown 预览（不落盘）；「导出到文件夹…」选择目录后写出，重复导出自动去重，**人工编辑过的文件不会被覆盖**。

## 归档与删除

- **归档**：计划从列表沉底但条目与打卡记录全部保留，Toast 可撤销；
- **删除**：需二次确认；删除计划、条目与条目打卡，默认一并删除**本计划独占的自动生成待办及其打卡**。手工待办与其他计划共用的待办保留。全部清理在同一事务中完成，不可恢复。
- **删除 action**：在「数据 → 对象类型 → 学习 → 已有对象」打开计划详情，选择「删除学习计划」后执行；`id` 自动预填，`delete_todos` 默认 `true`，填 `false` 可保留待办。AI 可通过 `delete_study_plan` 或 `invoke_action` 调用，删除前须确认范围。
- 旧版本删除计划后留下的待办不会自动追删；需要根据来源与 `plan:<id>` 标签核实后单独清理。

## 间隔复习

学完一个知识点，对 AI 说「为《知识点》按遗忘曲线生成复习计划」，AI 调用 `create_review_schedule` 按 **D+1 / D+3 / D+7 / D+21** 生成复习条目与待办，复习到期会出现在「今日」面板。



## 数据面板联动

计划和条目也可在数据面板查看；完成、撤销和删除共用业务动作，通用字段写入不能代替。关联动作停用时组合操作整体拒绝，避免只完成一部分联动。
