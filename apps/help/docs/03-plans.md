## 页面操作区

顶部左侧直接显示「计划 / 课程」切换，右侧显示当前计划、草案或课程数量，不再重复显示「学习计划」大标题。计划详情保留紧凑的具体计划名称与进度；条目详情头部显示状态。

顶部「上手课程」可直接打开随 App 提供的「Dayfolio 上手之旅」，无需先建计划。课程也收录在「课程」列表中；当前提供总览和第 1 天样课。

## 计划从哪里来

计划主要通过 **AI 创建**：在 zcode 里对 AI 说「为《某某课程》制定 14 天学习计划，每天 1 小时」，AI 调用 MCP 工具 `create_study_plan` 生成逐日安排，并**自动为每天生成关联待办**。App 内的「学习」面板负责查看与打卡。

走**学习闭环**（推荐，见「学习闭环」一节）时，AI 先生成**待确认草案**：面板列表顶部会出现草案卡片，展示逐日安排与「假设清单」（AI 缺省处理过的信息），由你**确认生成计划**或**取消草案**（取消不产生任何计划与待办）。

## 未排期专题草案（日期待定先存后排）

材料已到位但**还没定什么时候学**（比如一批专题文稿先存着）时，AI 用 `draft_study_topic` 保存**无日期专题草案**：只存主题大纲、知识点分解、材料来源和可选的**样课课程关联**（样课未确认也能关联）——**不排日程、不产待办、不占每日预算**。这类卡片在列表里标「未排期专题草案」，展示知识点大纲（名称/时长/前置依赖），等你给出**起始日期与每日预算**后再排期：

1. 点卡片上的**「排期…」**，填起始日期与每日预算（10~600 分钟）；
2. **「预览排期」**先做只读预览：逐日安排、依赖顺序（先修在前）、与其他**进行中计划**的**每日预算冲突**（既有占用 + 新排超出预算的日子）与**知识点重复**预警、透明规则假设——有预警会黄条逐条列出；
3. 你核对后点**「确认排期」**才真正落库（**服务端硬校验**：按当下状态重算超预算日期，与你预览时知晓的集合必须完全一致，预览后其他计划有变动会被拒并要求重新预览；重复提交幂等）；换起始日期或预算可以重新预览、重新排期；
4. 排期后的草案回到原有流程：展示逐日安排，由你**确认生成计划**（生成逐日条目与待办）或**取消草案**。**确认时服务端会再次硬校验**——点「确认生成计划」会先取**当下最新**的超预算日期，若仍有冲突会在弹窗里**逐日列出**并要求你显式同意（不同意可取消、改回调整起始日期/预算）；若你在弹窗停留期间其他进行中计划发生变动，确认会被服务端拒绝并提示原因，刷新后重新确认即可。绝不会跳过你自动默认同意。

排期前草案内容仍可由 AI 更新（大纲/知识点/材料/课程关联）；排期后内容锁定，调整走取消重建或计划调整建议。**样课确认门禁不变**：课程与计划的绑定仍以课程包导入为准，确认样课始终是你在 App 内的亲自操作。

## 计划列表

每张计划卡片显示标题、日期范围、目标、进度条与状态（进行中 / 已完成 / 已归档）。点卡片进入详情。

顶部切换到**「课程」页签**可浏览所有课程：课程没有独立的侧栏入口（学习入口只有「学习」一个），课程页集中列出所有课程，包括未绑定计划的课程，显示名称、状态与绑定关系；点击可在本面板内打开课程总览（见「课程」一章）。

## 计划详情

- 条目**按日期分组**为每日卡片，今天的分组会高亮标注「今天 · 日期」；
- 每条目带类型图标：**学习 / 复习 / 练习 / 休息**，右侧显示类型与时长（如「学习 · 45m」）；
- 关联知识点的条目显示**掌握徽标**（未知 / 薄弱 / 巩固中 / 良好，悬停看判定依据）——它只反映**测评证据**，与打卡进度是两回事；
- 点左侧**圆钮**打卡，再点一次撤销；
- 状态为待处理时可点「跳过」，当天不想做时不必硬打卡；
- 顶部进度条实时反映 `已完成/总条目`，来自学习闭环的计划还会显示每日时间预算。

## 关联课程的计划：每日摘要卡与「待生成」

课程导入时若绑定了这个计划（见「课程」一章），详情页会有明显变化：

- 顶部出现**关联课程条**：课程标题、已生成天数，以及**「进入课程总览」**按钮（在本面板内打开该课程总览，返回时回到计划详情并恢复原滚动位置）；
- 每个日期组标注**「第 N 天」**徽标——计划第 N 个日期对应课程第 N 天；
- 已生成的天显示**每日摘要卡**（讲义标题、核心概念、时长、已读/可阅读状态），点击**直达当天完整讲义与自测**，读毕点「返回计划详情」原位回到这里；
- 尚未生成的天明确显示**「讲义待生成」**：当天该按计划大纲做什么一目了然（条目照常打卡），讲义待课程完整版生成后解锁（在课程总览确认样课并请求完整版）。

计划条目的打卡、进度与掌握徽标不受课程影响——两边互不干扰。

## 学习记录 / 计划调整 / 知识卡片

学习闭环的计划详情底部有三个新区块（数据由 AI 经 MCP 写入，App 只展示与确认）：

- **学习记录**：每次学习会话的时间、自己的解释、疑问与材料，按时间列出；
- **计划调整**：「查看调整建议」只做**预览**（漏做改期 / 薄弱补复习，附判定依据）；勾选后「应用选中」才写库（改期会同步待办截止日），点「取消」不做任何变更；
- **知识卡片**：「预览待审卡片」生成 Obsidian Markdown 预览（不落盘）；「导出到文件夹…」选择目录后写出，重复导出自动去重，**人工编辑过的文件不会被覆盖**。

## 归档与删除

- **归档**：计划从列表沉底但条目与打卡记录全部保留，Toast 可撤销；
- **删除**：需二次确认；删除计划、条目与条目打卡，默认一并删除**本计划独占的自动生成待办及其打卡**。手工待办与其他计划共用的待办保留。全部清理在同一事务中完成，不可恢复。
- **删除 action**：在「数据 → 对象类型 → 学习 → 已有对象」打开计划详情，选择「删除学习计划」后执行；`id` 自动预填，`delete_todos` 默认 `true`，填 `false` 可保留待办。AI 可通过 `delete_study_plan` 或 `invoke_action` 调用，删除前须确认范围。
- 旧版本删除计划后留下的待办不会自动追删；需要根据来源与 `plan:<id>` 标签核实后单独清理。

## 间隔复习

学完一个知识点，对 AI 说「为《知识点》按遗忘曲线生成复习计划」，AI 调用 `create_review_schedule` 按 **D+1 / D+3 / D+7 / D+21** 生成复习条目与待办，复习到期会出现在「今日」面板。



## 数据面板联动

计划和条目也可在数据面板查看；完成、撤销和删除共用业务动作，通用字段写入不能代替。关联动作停用时组合操作整体拒绝，避免只完成一部分联动。
