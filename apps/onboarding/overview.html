Dayfolio 上手之旅

用五分钟认识 Dayfolio，分清应用、课程内容与外部 AI 助手各自承担的工作。

你会学到什么

  • 了解本地数据库与课程文件的保存方式。
  • 从「学习计划」进入课程总览和逐日讲义。
  • 理解完成任务、记录学习和证明掌握之间的区别。
  • 了解 MCP 如何让外部 AI 助手操作同一份数据，以及统一 Dayfolio 技能中的教学与赛事能力。

学习安排

计划列表卡片压缩留白，日期、目标与进度分层显示；计划详情顶部集中显示目标、日期、预算和真实进度，下方「每日安排」按第几天和日期分组，「今天」单独标记。讲义标题与概念分行展示；计划与条目详情的 AI 检验说明可从「使用说明与提示词」展开。条目详情将标题与末尾明确标注的目标分开，集中展示日期和进度；课件标题与版本分行显示，讲义字号和行宽适合连续阅读，仍可全屏阅读。

学习计划与每日安排以卡片展示课件已读、评测已做和笔记已输出。进入某项学习详情，直接显示完整课件和自测题，提交答案后查看解析，填写笔记即可保存，无需填写学习用时；底部可标记完成。「AI 检验学习成果」紧跟评测、位于学习笔记之前，点击复制提示词，粘贴到已连接 Dayfolio 的 AI 对话，按一次一道题检验理解。

已指定课程的学习草案，在确认生成计划时自动关联课程。确认后可在「计划 / 课程」两处核对绑定名称；旧版遗漏的关联可由助手重复确认原草案补齐，不重复创建计划或待办。

当前提供第 1 天样课。先阅读讲义并完成自测；看完后在对话中说「样课确认，继续生成完整版」，助手即可记录当前版本的确认并继续生成、导入，无需在 App 点击确认。确认后「样课」标识和讲义确认提示会隐藏；内容变化需重新确认时再次显示。若课程关联了更长的计划，尚无讲义的天数会显示「待生成」。

每日讲义有独立的 v1、v2 版本标识。更新哪一课，就增加哪一课的版本；相同内容重复导入、阅读与答题不增加版本。已有讲义从 v1 开始记录后续更新。

清理课程时，可在课程详情点击「删除课程」，或在对话中指定课程并确认删除。总览、讲义和阅读自测记录会一并删除；学习计划和待办需要单独指定删除。

如何进入

侧边栏依次为「今日、待办、新闻、学习、知识库、自媒体、工具箱」，「新闻」位于「学习」上方。打开「学习」，点击顶部「上手课程」，或切换到「课程」后点击课程名称。课程总览与每天的讲义分别阅读，总览不计入日课进度。

总览与讲义随阅读区域宽度自适应展开，内容区居中、段落左对齐；正文工具栏的「全屏」可扩大阅读区域。

正式 App 首次启动会自动收录本课程，升级时也会补入；不创建计划或待办，不替你确认样课。若课程库中已存在本课程，保留原内容与进度。隔离预览中的确认和进度只影响临时数据。

查看今天的安排

打开「今日」，先在上方日历与当日明细查看当天待办，点击条目进入详情并完成。当日明细与「今日学习」每项各用一张卡片，标题完整换行，时间和来源等信息放在下方。日历下方保留「已逾期」与「今日学习」，不再重复列出「今天到期」。

调整每日新闻

先到侧边栏「设置 → 配置 Agent」，选择本机已安装并登录的 Codex、Claude Code 或 Gemini CLI，在分组卡片中点击 Agent 条目展开配置，按左侧说明在右侧填写路径、模型或使用安装登录按钮，在条目内检查连接，再点击底部「保存配置」；再次点击条目可收起。也可点击条目内的「复制给ai」，将接入任务粘贴到 Agent 对话中，由它检查、保存并回读配置；复制本身不完成接入。打开「新闻 → AI 采集」编辑并保存要求，再点「更新今日新闻」直接调用所选 Agent 核实来源、入库并自动刷新。也可在已接入 Dayfolio 的 Agent 对话中说「按保存要求更新今日新闻」，由当前助手直接完成。App 不携带 Agent 运行时，不再创建请求等待下一次会话。

练习：修改一条关注方向并保存，返回后重新进入核对；打开一条 AI 简报，核对逐条摘要与「阅读来源」入口。

导入 HTML 工具

工具箱统一导入 HTML 页面，横向卡片按分类排列；打开后可返回列表，删除会移除工具文件，不提供工具包安装和版本管理。

接入待办的工具可点击「加入待办」，由 App 预览并确认；批量预览可勾选，已有事项会跳过。欧冠页可添加单场比赛或球队当前已知的未来比赛，只保存本次内容，不持续关注或自动同步改期。

预览中会显示待办分类，默认使用工具名称，也可以由页面按内容声明。第一次确认添加新事项时才创建或复用分类，取消不会留下空分类。添加后可在「待办」按分类筛选，通过日历「新建日程」旁的更多菜单 →「管理分类」控制显示、编辑名称与颜色，或确认删除自定义分类。删除分类保留待办和完成记录，系统与事件来源分类可隐藏；显示时区也在该弹窗设置。
