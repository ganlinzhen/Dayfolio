Dayfolio 上手之旅 · 第 1 天

欢迎打开 Dayfolio！这份样课带你用五分钟认识本地数据、学习闭环与 AI 协作方式。

本地优先

Dayfolio 将业务数据保存在本机 SQLite 数据库，课程讲义等资产保存在数据库旁的目录。App 与 MCP 指向同一数据库时，才能看到一致的数据。外部 AI 助手及其联网行为遵循你所使用客户端的配置。

查看今天的安排

打开「今日」，先在日历或当日明细查看当天待办，点击条目进入详情并完成。当日明细与「今日学习」每项各用一张卡片，标题完整换行，时间和来源等信息放在下方。日历下方保留「已逾期」与「今日学习」，不再重复展示「今天到期」列表。

练习：在日历找到一项当天待办，打开详情后返回，核对日历下方直接展示逾期事项（如有）与今日学习。

找到计划与课程

侧边栏依次为「今日、待办、新闻、学习、知识库、自媒体、工具箱」，「新闻」位于「学习」上方。学习入口是「学习」。顶部「计划 / 课程」切换默认显示计划；点击「上手课程」可以直接打开本课，切换到「课程」可以查看所有已导入课程，包括尚未关联计划的课程。

正式 App 首次启动会自动收录这份上手样课，已有用户升级后也会补入。它不创建计划或待办，不代你确认样课；如果已经收录，则保留原课程内容与进度。

点击课程进入总览，再打开当天讲义。独立总览不算第 1 天，也不占讲义阅读进度。计划中没有讲义的天数会显示「待生成」。

总览和讲义会随阅读区域自适应展开，内容区居中、正文左对齐。点击正文工具栏的「全屏」可扩大阅读区域，退出后自动适配原宽度。

日课卡片、计划详情的讲义摘要和讲义阅读页显示本课版本，例如 v1。正文或教学资料实际更新后，本课递增为 v2、v3；其他课次保持原版本。相同内容重导、已读和答题不会增加版本，已有讲义从 v1 开始记录。独立总览不计入逐课版本。

课程详情的「删除课程」可清理总览、讲义、阅读自测记录及生成请求，也可在对话中指定课程并确认删除；操作不可恢复。删除课程保留计划与待办；若要整组清理，在对话中明确指定计划、课程及关联待办。

学习闭环

计划列表卡片压缩留白，日期、目标与进度分层显示；计划详情顶部集中显示目标、日期、预算和真实进度，下方「每日安排」按第几天和日期分组，「今天」单独标记。讲义标题与概念分行展示；计划与条目详情的 AI 检验说明可从「使用说明与提示词」展开。条目详情将标题与末尾明确标注的目标分开，集中展示日期和进度；课件标题与版本分行显示，讲义字号和行宽适合连续阅读，仍可全屏阅读。

计划列表与每日安排使用卡片，分别显示课件已读、评测已做、笔记已输出。进入一项安排后，当前详情直接显示完整课件、核心概念、源码导读与自测题。选择答案并点「提交答案」保存和查看解析；用自己的话写笔记后，点击「保存学习笔记」，无需填写学习用时。「AI 检验学习成果」紧跟评测、位于学习笔记之前；完成、撤销、跳过或恢复待办均在底部操作；完成安排不会代替掌握证据。

在计划详情可检验整个计划，在条目详情只检验这一项。点击「AI 检验学习成果」中的复制按钮，把提示词粘贴到已连接 Dayfolio 的 AI 客户端。助手先读取对应课件、笔记和测评，再主动一次问一个问题，等你回答并纠正理解；结束前核对笔记，实际用时可省略，仅你主动提供时记录，再记录真实证据。复制提示词不会启动对话或自动标记完成。

计划负责安排日期，课程负责提供讲义。学习之后可以记录会话与测评证据，再安排复习。完成任务或打卡记录的是完成情况，不能直接说明已经掌握知识。

让助手为已有课程保存学习草案时，应明确指定课程。确认草案生成计划后，课程卡显示关联计划，计划卡显示关联课程。若旧版已建计划却漏了关联，可让助手重复确认原草案补齐关系，原计划和待办会保留；课程已有其他绑定时不能改绑。

AI 接入

通过 MCP，外部 AI 客户端可以查询与修改同一份数据，例如添加待办、制定计划、导入课程和提交新闻。Codex 中统一使用 Dayfolio 技能，教学和赛事页面已包含其中，无需选择额外技能。

新闻由 App 直接调用 Agent，或由当前对话中的助手直接核实并提交。课程需要你在 App 阅读样课，看完后在对话中说「样课确认，继续生成完整版」，由助手记录当前版本确认、创建并认领请求、编写与导入讲义，无需在 App 点击确认。确认后日课卡片的「样课」标识和讲义确认提示会隐藏；样课变更使确认过期后恢复显示。新闻可通过「更新今日新闻」调用设置中的 Agent；课程等请求仍等待外部助手执行。

使用弹窗

应用内弹窗在左上方显示标题，右上角可以关闭；确认按钮统一放在右下角，主要操作在最后。长内容在正文区滚动，底部按钮保持可见。Tab 和 Shift+Tab 在弹窗内切换焦点，Esc 可关闭并返回原入口；导入或正在提交时暂时不能关闭。系统文件选择和系统确认框沿用 macOS 样式。

工具箱只收纳 HTML 页面，以图标在左、名称在右的横向卡片按分类排列。点「导入 HTML」选择页面与配套文件；点击卡片打开，悬停或聚焦后用垃圾桶删除。工具不再提供编辑、启停、卸载、版本或回滚入口，也不需要工具包。

练习：打开「工具箱 → 导入 HTML」，核对标题、关闭按钮和底部的「取消 / 导入」，按 Esc 返回列表，不提交练习数据。

接入待办的 HTML 工具可以请求添加事项。欧冠页每场比赛的「加入待办」会打开 App 预览；球队详情的「批量加入待办」只列出当前已知的未来比赛。勾选后确认才创建，重复添加会跳过已有、已完成或已移除的记录，保留个人修改；关注球队和收藏比赛仍只用于页面筛选，不自动跟随新比赛或改期。

练习：在已接入待办的工具中打开单场预览，核对标题、显示时区和开球时间，再取消；打开球队批量预览，尝试取消勾选一场并观察数量，最后按 Esc 关闭，确认没有新增练习待办。

预览中的「待办分类」默认沿用工具名，页面也可声明合适名称。首次确认并实际创建新待办时才创建或复用分类，取消、全部重复或添加失败均不留下空分类。待办行会显示分类，顶部可按分类筛选；日历「新建日程」旁的更多菜单 →「管理分类」可单独隐藏分类，保留待办与完成记录。后续添加会保留已有分类的名称、颜色和隐藏偏好。

在「管理分类」弹窗中，可勾选显示哪些分类，修改分类名称和颜色，或确认删除自定义分类。删除会把待办移入基础待办、日程移入本地日程分类，保留内容与完成状态；取消删除不改数据。系统分类和由事件来源维护的分类不可单独删除，可隐藏。显示时区也在弹窗底部设置。

练习：打开日历更多菜单 →「管理分类」，隐藏再恢复一个分类，编辑练习分类的名称与颜色；点删除阅读影响说明后取消，核对分类与待办仍在。不要为练习删除自己的真实分类。

练习：在单场预览中核对分类名，再取消，确认待办分类列表没有新增记录；之后为真正需要的事项确认添加，再到「待办」选择对应分类，核对归属和数量。

动手练习

另选一个学习计划，核对详情顶部的目标与进度，在「每日安排」找到当天分组并展开 AI 检验的使用说明，查看紧凑卡片中的三项进度，再进入一项安排，核对标题、目标和状态；在窄窗口检查课件标题换行并切换全屏，再直接阅读课件、提交自测，再写下自己的理解并保存笔记。复制 AI 检验提示词，在已连接 Dayfolio 的对话中回答第一题；核对记录回流后，再决定是否在详情底部标记完成。

  1. 为一门已有课程确认学习计划后，在「计划 / 课程」两处核对关联名称；如果仍显示未关联，请让助手核对原草案中的课程 ID。
  2. 核对侧边栏「新闻」位于「学习」上方，分别点击两个入口确认当前栏目；在「学习」顶部点击「上手课程」，打开本课程总览。
  3. 回到课程页，打开第 1 天讲义，找到课程详情的「删除课程」入口但不要在练习中删除本课；观察总览与日课的区别，核对卡片和阅读页的 v1 课次版本；调整窗口宽度并切换「全屏」，检查内容区是否居中、左右留白是否对称。
  4. 如果已接入 MCP，让助手「看看有哪些课程」，核对是否与 App 的课程列表一致；看完样课后可在对话中说「样课确认」，观察切回 App 后的状态变化，确认「样课」标识和讲义确认提示已经隐藏。只有希望续写时再说「继续生成完整版」。

隔离预览中的步骤只影响临时数据。未接入 MCP 时可先跳过第 3 步。已经导入的课程不会随 App 升级自动覆盖内容，后续讲义更新仍走课程导入流程。

自测与解析

问题一：为什么 AI 查到的课程可能与 App 不一致？

先检查 App 与 MCP 是否指向同一个数据库。隔离预览使用临时数据库，其内容不会出现在正式版课程列表。

问题二：创建课程生成请求后，讲义会立即出现吗？

不会。需要外部助手认领请求、编写并导入讲义，完成核验后才能看到完整内容。

问题三：打卡完成是否等于掌握？

不等于。完成情况与掌握情况分开记录，掌握需要学习测评证据。

继续查阅

打开侧边栏「帮助」，查阅「学习」「课程」「学习闭环」「MCP 与 AI 接入」「新闻」与「预览沙盒」的对应说明。本课依据这些模块的实际行为维护。

配置 Agent 与更新新闻

练习：在设置中选择 Agent 并保存，回到新闻页直接更新，观察进度与实际收录结果；核对停止和重试会保留已收录内容。再了解对话更新入口，两种方式都应真实完成采集再汇报。

先到侧边栏「设置 → 配置 Agent」，选择本机已安装并登录的 Codex、Claude Code 或 Gemini CLI，在分组卡片中点击 Agent 条目展开配置，按左侧说明在右侧填写路径、模型或使用安装登录按钮，在条目内检查连接，再点击底部「保存配置」；再次点击条目可收起。也可点击条目内的「复制给ai」，将接入任务粘贴到 Agent 对话中，由它检查、保存并回读配置；复制本身不完成接入。打开「新闻 → AI 采集」编辑并保存要求，再点「更新今日新闻」直接调用所选 Agent 核实来源、入库并自动刷新。也可在已接入 Dayfolio 的 Agent 对话中说「按保存要求更新今日新闻」，由当前助手直接完成。App 不携带 Agent 运行时，不再创建请求等待下一次会话。

练习：修改一条关注方向并保存，返回后重新进入核对；打开一条 AI 简报，核对逐条摘要与「阅读来源」入口。
