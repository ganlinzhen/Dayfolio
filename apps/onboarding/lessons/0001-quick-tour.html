Dayfolio 上手之旅 · 第 1 天

欢迎打开 Dayfolio！这份样课带你用五分钟认识本地数据、学习闭环与 AI 协作方式。

本地优先

Dayfolio 将业务数据保存在本机 SQLite 数据库，课程讲义等资产保存在数据库旁的目录。App 与 MCP 指向同一数据库时，才能看到一致的数据。外部 AI 助手及其联网行为遵循你所使用客户端的配置。

页面操作栏和弹窗底部的文字按钮等高，深色底标识主操作，次操作保留清晰描边；宽度随文字长度调整。列表内辅助操作保留紧凑尺寸。可在「工具箱」核对「编辑 / 导入」和编辑模式中的「管理分类 / 完成编辑」，再打开导入弹窗查看底部操作。

查看今天的安排

打开「今日」，先在日历或当日明细查看当天待办，点击条目进入详情并完成。明细标题右侧可切换「今日 / 本周 / 本月」，包含未完成与已完成事项；本周为周一至周日，本月为自然月，按日期分组并沿用日历分类显示设置。网格选日可查看该日明细，点「今日」回到今天。明细每项各用一张卡片，标题完整换行，时间和来源等信息放在下方。事项明细之后，仅在有逾期待办时展示「已逾期」，学习安排在日历查看，打卡从「学习」面板的条目详情进入，不再单独展示「今日学习」或重复展示「今天到期」列表。

点击日历事项，在旁边浮层查看详情或完成待办。周视图按周一到周日排列，周日在最右侧；点击「今天」回到当前所在周，左右箭头翻周。周视图点空档先出现 15 分钟草稿，拖动下边缘调整结束时间，松手后填写标题并创建。练习：点一个空档，向下拖动草稿底边，再取消，核对没有留下空白日程。

练习：在日历找到一项当天待办，打开详情后返回，依次切换「今日 / 本周 / 本月」，核对日期范围与已完成、未完成标识；列表之外仍保留逾期事项（如有）；再从「学习」打开计划的条目详情，找到「标记完成」入口。

找到计划与课程

打开「待办」，点击「接下来要做什么？」按需展开新增：可快速选今天、明天或暂不安排，按需填写备注与标签。时间段须填写开始时间；仅确定日期时选「仅日期」。Esc 收起并保留草稿，「取消新增」清空草稿。

用「今天 / 已逾期 / 未来 7 天 / 无日期」聚焦安排，叠加分类、优先级和标题或备注搜索；「清除筛选」保留状态选择。点击分组可收起，组内可按时间、优先级或最近添加排序。点击标题编辑备注、标签和优先级；保存检查并发版本，修改备注不会改排期或停止来源跟随。

练习：添加一条「仅日期」的练习待办，筛选今天，点击标题补充备注并保存；勾选完成后用提示中的「撤销」重新打开。删除前核对确认提示，撤销删除只重建独立待办，不恢复来源关联。未在输入框中时可按 N 新增、/ 搜索。

侧边栏依次为「今日、待办、新闻、学习、知识库、自媒体、工具箱」，「新闻」位于「学习」上方。学习入口是「学习」。顶部「计划 / 课程」切换默认显示计划；点击「上手课程」可以直接打开本课，切换到「课程」可以查看所有已导入课程，包括尚未关联计划的课程。

正式 App 首次启动会自动收录这份上手样课，已有用户升级后也会补入。它不创建计划或待办，不代你确认样课；如果已经收录，则保留原课程内容与进度。

点击课程进入总览，再打开当天讲义。独立总览不算第 1 天，也不占讲义阅读进度。计划中没有讲义的天数会显示「待生成」。

总览和讲义会随阅读区域自适应展开，内容区居中、正文左对齐。点击正文工具栏的「全屏」可扩大阅读区域，退出后自动适配原宽度。

日课卡片、计划详情的讲义摘要和讲义阅读页显示本课版本，例如 v1。正文或教学资料实际更新后，本课递增为 v2、v3；其他课次保持原版本。相同内容重导、已读和答题不会增加版本，已有讲义从 v1 开始记录。独立总览不计入逐课版本。

课程详情的「删除课程」可清理总览、讲义、阅读自测记录及生成请求，也可在对话中指定课程并确认删除；操作不可恢复。删除课程保留计划与待办；若要整组清理，在对话中明确指定计划、课程及关联待办。

学习闭环

计划列表卡片压缩留白，日期、目标与进度分层显示；计划详情顶部集中显示目标、日期、预算和真实进度，下方「每日安排」按第几天和日期分组，「今天」单独标记。讲义标题与概念分行展示；计划与条目详情的 AI 检验说明可从「使用说明与提示词」展开。条目详情将标题与末尾明确标注的目标分开，集中展示日期和进度；课件标题与版本分行显示，讲义字号和行宽适合连续阅读，仍可全屏阅读。

计划列表与每日安排使用卡片，分别显示课件已读、评测已做、笔记已输出。进入一项安排后，当前详情直接显示完整课件、核心概念、源码导读与自测题。选择答案并点「提交答案」保存和查看解析；用自己的话写笔记后，点击「保存学习笔记」，无需填写学习用时。「AI 检验学习成果」紧跟评测、位于学习笔记之前；完成、撤销、跳过或恢复待办均在底部操作；完成安排不会代替掌握证据。

在计划详情可检验整个计划，在条目详情只检验这一项。点击「AI 检验学习成果」中的复制按钮，把提示词粘贴到已连接 Dayfolio 的 AI 客户端。助手先读取对应课件、笔记和测评，再主动一次问一个问题，等你回答并纠正理解；结束前核对笔记，实际用时可省略，仅你主动提供时记录，再记录真实证据。复制提示词不会启动对话或自动标记完成。

计划负责安排日期，课程负责提供讲义。学习之后可以记录会话与测评证据，再安排复习。完成任务或打卡记录的是完成情况，不能直接说明已经掌握知识。

让助手为已有课程保存学习草案时，应明确指定课程。确认草案生成计划后，课程卡显示关联计划，计划卡显示关联课程。若旧版已建计划却漏了关联，可让助手重复确认原草案补齐关系，原计划和待办会保留；课程已有其他绑定时不能改绑。

AI 接入

通过 MCP，外部 AI 客户端可以查询与修改同一份数据，例如添加待办、制定计划、导入课程和提交新闻。Codex 中统一使用 Dayfolio 技能，教学和赛事页面已包含其中，无需选择额外技能。

新闻由 App 直接调用 Agent，或由当前对话中的助手直接核实并提交。课程需要你在 App 阅读样课，看完后在对话中说「样课确认，继续生成完整版」，由助手记录当前版本确认、创建并认领请求、编写与导入讲义，无需在 App 点击确认。确认后日课卡片的「样课」标识和讲义确认提示会隐藏；样课变更使确认过期后恢复显示。新闻可通过「更新新闻」调用设置中的 Agent；课程等请求仍等待外部助手执行。

使用弹窗

应用内弹窗在左上方显示标题，右上角可以关闭；确认按钮统一放在右下角，主要操作在最后。长内容在正文区滚动，底部按钮保持可见。Tab 和 Shift+Tab 在弹窗内切换焦点，Esc 可关闭并返回原入口；导入或正在提交时暂时不能关闭。系统文件选择和系统确认框沿用 macOS 样式。

工具箱只收纳 HTML 页面，以图标在左、名称在右的横向卡片按分类排列。首页只有「编辑」与「导入」。点「导入」选择页面及配套文件，含子目录时选择整个文件夹；点击卡片打开。进入编辑模式可管理分类、用上下箭头排序并切换分组，这些整理即时保存；点击卡片编辑名称、内置图标或图片、背景、分类、HTML 入口与文件。表单需保存后生效；不替换文件会保留现有资源，替换须包含完整文件集。删除在工具编辑弹窗底部，确认后不可恢复；卡片不显示删除按钮，也不需要工具包。

练习：打开「工具箱 → 导入」，核对标题、关闭按钮和底部的「取消 / 导入」，按 Esc 返回列表，不提交练习数据。随后进入「编辑」，核对分类入口、卡片上的排序和分类控件，再点「完成编辑」。

接入待办的 HTML 工具可以请求添加事项。欧冠页每场比赛的「加入待办」会打开 App 预览；球队详情的「批量加入待办」只列出当前已知的未来比赛。勾选后确认才创建，重复添加会跳过已有、已完成或已移除的记录，保留个人修改；球队的「加入筛选」和收藏只改变页面筛选；持续关注通过单独入口确认。

练习：在已接入待办的工具中打开单场预览，核对标题、显示时区和开球时间，再取消；打开球队批量预览，尝试取消勾选一场并观察数量，最后按 Esc 关闭，确认没有新增练习待办。

欧冠每场比赛另有「持续关注」，球队详情可「持续关注赛程」。核对宿主范围与分类后确认，之后资料更新会同步改期，并为分组新增的未来事项加入待办；单场与分组重叠不重复。资料由页面或助手核实并发布，关闭页面更新完整文件中的来源清单也会同步，持续关注不会自行联网采集。

手动改标题或时间后转为个人安排，自动更新不覆盖；备注、标签、优先级保留。已完成记录不改、不重开，已删除不自动恢复。点比赛的「详情」、待办的「来源详情」或日历项可查看最新来源，停止关注并保留待办，或在核对影响后明确恢复跟随。

练习：用练习事项打开持续关注预览后取消，确认未生成待办或分类；关注一个练习分组，核对后续资料更新仍复用原待办。观察个人安排与完成保护提示，取消关注后确认待办仍在，不为练习修改真实赛程。

预览中的「待办分类」默认沿用工具名，页面也可声明合适名称。首次确认并实际创建新待办时才创建或复用分类，取消、全部重复或添加失败均不留下空分类。待办行会显示分类，顶部可按分类筛选；日历「新建日程」旁的更多菜单 →「管理分类」可单独隐藏分类，保留待办与完成记录。后续添加会保留已有分类的名称、颜色和隐藏偏好。

在「管理分类」弹窗中，可勾选显示哪些分类，修改分类名称和颜色，或确认删除自定义分类。删除会把待办移入基础待办、日程移入本地日程分类，保留内容与完成状态；取消删除不改数据。系统分类和由事件来源维护的分类不可单独删除，可隐藏。显示时区也在弹窗底部设置。

练习：打开日历更多菜单 →「管理分类」，隐藏再恢复一个分类，编辑练习分类的名称与颜色；点删除阅读影响说明后取消，核对分类与待办仍在。不要为练习删除自己的真实分类。

练习：在单场预览中核对分类名，再取消，确认待办分类列表没有新增记录；之后为真正需要的事项确认添加，再到「待办」选择对应分类，核对归属和数量。

动手练习

另选一个学习计划，核对详情顶部的目标与进度，在「每日安排」找到当天分组并展开 AI 检验的使用说明，查看紧凑卡片中的三项进度，再进入一项安排，核对标题、目标和状态；在窄窗口检查课件标题换行并切换全屏，再直接阅读课件、提交自测，再写下自己的理解并保存笔记。复制 AI 检验提示词，在已连接 Dayfolio 的对话中回答第一题；核对记录回流后，再决定是否在详情底部标记完成。

  1. 为一门已有课程确认学习计划后，在「计划 / 课程」两处核对关联名称；如果仍显示未关联，请让助手核对原草案中的课程 ID。
  2. 核对侧边栏「新闻」位于「学习」上方，分别点击两个入口确认当前栏目；在「学习」顶部点击「上手课程」，打开本课程总览。
  3. 回到课程页，打开第 1 天讲义，找到课程详情的「删除课程」入口但不要在练习中删除本课；观察总览与日课的区别，核对卡片和阅读页的 v1 课次版本；调整窗口宽度并切换「全屏」，检查内容区是否居中、左右留白是否对称。
  4. 如果已接入 MCP，让助手「看看有哪些课程」，核对是否与 App 的课程列表一致；看完样课后可在对话中说「样课确认」，观察切回 App 后的状态变化，确认「样课」标识和讲义确认提示已经隐藏。只有希望续写时再说「继续生成完整版」。

隔离预览中的步骤只影响临时数据。未接入 MCP 时可先跳过第 3 步。已经导入的课程不会随 App 升级自动覆盖内容，后续讲义更新仍走课程导入流程。

自测与解析

问题一：为什么 AI 查到的课程可能与 App 不一致？

先检查 App 与 MCP 是否指向同一个数据库。隔离预览使用临时数据库，其内容不会出现在正式版课程列表。

问题二：创建课程生成请求后，讲义会立即出现吗？

不会。需要外部助手认领请求、编写并导入讲义，完成核验后才能看到完整内容。

问题三：打卡完成是否等于掌握？

不等于。完成情况与掌握情况分开记录，掌握需要学习测评证据。

继续查阅

打开侧边栏「帮助」，查阅「学习」「课程」「学习闭环」「MCP 与 AI 接入」「新闻」与「预览沙盒」的对应说明。本课依据这些模块的实际行为维护。

配置 Agent 与更新新闻

先在「设置 → 配置 Agent」选择已安装并登录的本机 CLI，检查连接并保存。进入新闻配置，按国内、国际、AI、时事关注调整模块范围、顺序、数量与摘要/配图要求，预览动态采集要求后保存；俄乌与美伊共用时事模块，不作为永久栏目。首页每天每模块只有一条记录，显示 AI 对重点几则消息的综合总结；点击进入该日模块新闻列表，再点击单条进入详情。首页仅保留全部／未读／收藏／已隐藏与搜索，筛选按内部新闻状态匹配。每轮最多 10 则，同日多轮累计可以更多，来源不足如实显示。

保存配置不会立即联网：排序、重点数量、图片位置与背景等显示选项立即应用当前阅读；普通采集范围、来源偏好和摘要要求保留已开始任务的快照，尚未开始的模块和后续任务使用最新要求，不重置整轮配额。停用/移除模块、暂停/结束时事、关闭/清空学习会立即撤回相关执行授权。

默认北京时间 08:00、12:00、17:00 整点开始，也可手动更新。App 彻底退出或关机时不能采集，恢复后合并补最新一次；一轮先各模块少量重点，再补足。已有活动批次复用进度，停止保留结果。同日更新继续增加原模块条目的去重新闻数与总结，结果自动刷新，不需要「应用更新」；阅读中不跳页，返回逐级保留阅读位置。摘要先讲清事实，背景、影响、不确定性与来源图注分开；无可靠图时无图阅读，原始链接可查看详情。

兴趣学习默认关闭，由你开启。明确关注、减少主题/来源或隐藏新闻影响后续搜索，推荐提供实际理由；取消关注撤回订阅，少推荐保留关注但降低频率，移除候选只进入冷却，不取消订阅；时事可暂停、结束或设期限，旧点击不会自动恢复。新闻页的重要更正不改变已读状态。也可在 Agent 对话说「按模块配置更新新闻」，由当前助手完成搜索核实、提交和回读。

本次每日模块升级保留已经采集的模块新闻与单条状态，并回填每日记录；缺少综合总结时由 AI 阅读新闻后补写。更早 0.46 的旧新闻模型切换才按帮助说明清理旧抓取数据和旧模型。独立自媒体选题、素材和稿件保留，并保留旧新闻标题和原链快照，只解除新闻引用。升级后产生的新模块数据不在清理范围内。

练习：修改一个模块方向，预览动态要求再保存；确认首页同日同模块只有一条重点综合总结，点击模块进入新闻列表，再打开一条新闻核对摘要、图注与原链；返回时逐级回到原列表。查看兴趣开关与临时时事入口，了解暂停和清空范围；练习中不要删除真实新闻、清空真实兴趣或为验证启动重复采集。
