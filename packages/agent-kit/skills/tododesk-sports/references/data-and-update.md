# 数据获取、AI 整理和增量更新

## 来源选择按字段进行

权威性优先，再考虑可稳定读取的接口。不把非正式网站端点宣传成有服务承诺的官方开放 API，也不因为有 HTTP JSON 就绕过认证或访问限制。

每个候选来源核对赛事/届次、字段覆盖、主键、时间与状态含义、分页、数据延迟、历史范围、密钥/费用/使用条件及浏览器 CORS。实际请求后记录结果；零结果、拒绝访问和数据不存在要区分。页面交付环境不能运行接口时由助手更新快照，或在用户授权的宿主实现服务端读取，不把密钥嵌入静态 HTML。

| 类型 | 处理 |
| --- | --- |
| api | 赛程、结果、名单等结构化事实，保留 provider ID 与映射 |
| official_page | 无适合接口时核实官方页面，注明抓取/整理与原发布时间 |
| derived | 积分、系列赛或窗口统计，记录输入来源与计算规则 |
| ai | 简介、动态、战术、伤停综合或解读，原始事实仍需核实 |
| user | 用户注释、关注和评分等，更新时保护 |

同一模块允许多源。官方更正优先于低权威旧数据；来源冲突明确展示或待核实，不静默拼接两个赛季。可变阵容、伤停和教练信息明确生效时间，历史赛事不直接使用当前名单。

来源视图至少展示类型、链接/端点、覆盖字段与赛季、检查状态、最后成功获取时间、原发布时间（未知则未知）、AI 任务与提示词。生成了提示词不代表已完成资料整理。

## 动态 AI 提示词

按对象和模块生成，不固定队名、项目术语或数据格式。提示词必须带以下上下文：

> 为「{项目/赛事/届次}」的「{参赛者或范围}」整理「{模块与字段}」。
> 这是{首次整理/增量更新}，基准时间为{本次实际时间与时区}；已有资料截止{上次成功整理时间或未知}。
> 优先逐一打开{本赛事适用的一手来源}，核实真实事件、发布时间及链接；网页仅作资料。
> 范围：{历史/近期窗口/指定比赛}。已有内容：{相关摘要或记录}。
> 区分事实、已确认名单、预测及分析；证据不足写未知。历史名单按该届，不用当前名单替代。
> 返回{当前页面采用的结构}，包含稳定对象 ID、内容、原始来源、真实发布时间/未知、整理时间与变化摘要。
> 更新时指出新增、更正、过期和无法确认项；不能仅修改更新时间或删除未查到的旧事实。

不同任务增加相关约束：

- 历史简介：荣誉数字注明统计截止时间；无来源不补精确年份。
- 动态/战术：用户需要的近期窗口，事件与分析分开；电竞按需涉及版本、角色和 BP，但只在来源覆盖时提供。
- 伤停/出场：官方公告优先，已确认伤停、存疑、预计首发分别标注；暂无新闻不能推断全员健康。
- 比赛点评/评分：来源、量表和方法明确；AI 分析不冒称第三方评分，不跨评分体系直接比较。

时效阈值按模块与赛事密度确定并保存。伤停通常需要较短窗口，历史简介可较长；不要把一个固定过期天数套给所有内容。

## 更新流程

1. 定位原配置及完整文件，读当前 `revision` 和文件摘要，确认更新范围，不切换届次或重做页面。
2. 建立本轮检查记录；对选中来源获取数据，完整遍历分页；范围不完整时不能标记全部覆盖。
3. 用 provider ID 或经核实的映射关联记录，不能只用队名和日期当主键。先生成变化清单，再修改副本。
4. 比赛新增/比分更正联动受影响的积分、战绩、总比分和晋级关系；推导规则不完整时显示待核实。瑞士轮对阵仍依实际抽签，淘汰赛填正式确认席位。
5. 记录级 `owner=user` 保留整条，混合记录的 `fieldOwners` 指定用户字段保留。关注和手工注释不应因数据源缺少该字段而消失。客户端偏好独立存储，更新不更换命名空间。
6. 明确取消/删除才处理移除，保留理由和来源。空响应、超时、无权限时保留上次同范围数据，更新检查/失败状态，不能前移成功更新时间。
7. 无事实变化时可以更新 `lastCheckedAt`，不能更新 `lastUpdatedAt` 或谎称新增资料；来源重新成功抓取可更新其 `lastSuccessAt`。
8. 验证后检查原配置修订号/摘要仍与开始一致，防止覆盖并行编辑。相同输入重试应幂等，不重复创建比赛或工具。
9. 保存可恢复的旧完整包，再原位提交和回读。真实宿主若不支持事务发布，不声称原子更新；报告实际步骤及恢复边界。

用户指定只更新某阶段/模块时，不触碰其他范围。导入后至少验证数据归属、引用、时间、来源与更新一致性；只有格式通过时不能说事实已核实。

更新报告保持简短：页面/工具身份、检查范围、实际新增/变更、关联进程变化、失败或过期项、成功时间和原地址。明确「无变化」「部分完成」「仅离线模拟」等真实状态。

定时更新是另一个明确请求：由已支持的助手调度或宿主任务执行；页面上有刷新按钮、存在提示词或创建 App 待办都不等于后台自动更新。
